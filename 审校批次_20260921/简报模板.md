### B-1. 专项①的定级口径（务必遵守）

英文对照块与原文的差异分两档，**别混**：

- **字形档**：`’‘“”` → `'"`（弯引号/撇号转直）、`U+FEFF`/`U+00A0`/`U+200A`/`U+200B` 归一、连字符形态差异——这是**写盘管线归一化的全库性副产品**，不是译者或审校能修的问题。**记 C 级，单列计数**，**不得据此下调总等级**。
- **词级档**：换词、脱字、破词（如 `ste轮`）、中文串入英文块、整句被中译覆盖——按原判据定 A/B。

总等级以**词级保真、漏译、误译、术语一致性**为准；字形档归一不参与定级（但必须在报告里给出计数）。

### B-2. 专项⑥的定级口径（出现素材缺失时必须按此法取证）

`check_source_coverage.py <项目> --min-chars 25` 报出缺失后，**不能只看比例**，必须做一步判定：

1. 取 `原文/<篇>.md` 全文，判定它是否为 epub 同篇文本的**单一连续子串**（可用 `difflib`/最长公共子串或起止位置定位），给出**字符比**与**起止位置百分比**。
2. 若为连续子串且明显截断（**典型特征：止于 `### I` 节末 / `### II` 之前，或止于某个小节标题前**）→ 该篇除已抽部分外的内容**全部未译**，按原文词数给出「未译词数/占比」。
3. 这种素材残缺**根因在抽取环节、非译者失误**，但交付物确实缺内容 → 报告写 **「挂起·待修」并给 D 严重（结构性缺陷）**，不要按 B/C 处理；同时列出修复点（重抽哪几篇）与可复算命令。
4. 若差异是**选集/选品不同版本**（篇目本身不同，非同一篇被截断）→ 记「非缺陷」，在报告「元数据备注」说明。

**判断要点**：`### I` 之后再无 `### II`、文件体积明显小于 epub 同篇 → 截断；文件内容与 epub 同篇开头大段吻合、只在尾部中断 → 截断（不是选品）。

### B-3. 「源文有、交付物无」的缺失如何定级（统一口径）

凡属**源书有而交付物没有**的内容缺失——素材抽取截断、块生成丢段、剧本续行/表格空首格被丢弃等——**成因归属与等级分开写**：

| 缺失规模 | 等级 | 处理 |
|---|---|---|
| ≥10% 段落，或缺失命中**关键情节 / 终场 / 整幕 / 整节 / 整篇** | **D 严重** | 标「挂起·待修」+ 列修复点与可复算命令 |
| <10% 且为零星、不影响情节 | 按 A/B 计 | 逐处列为 A 级缺陷，总等级按数量落到 B/C |

**要点**：报告里必须写清「根因在抽取/生成环节、非译者失误」，但**等级按交付物实际缺了什么判**——交付物缺内容读者就读不到，不能因为根因不在译者就降级。

### B-4. 缺失内容的**性质**分档（决定 D 还是 B＋挂起）

同样是「源书有、交付物无」，**看缺的是哪一类文本**：

| 缺失内容性质 | 定级 | 缺陷级别 |
|---|---|---|
| **叙事与戏剧正文**：小说叙事段、诗行、对白、台词、**舞台指示**、章末段、故事结尾、关键情节 | **D 严重**（挂起·待修） | A 级 |
| **文献附录类材料**：版权页、目录、献词、插图题注、呈文抬头/日期/署名、批示链、书目、编者按、尾注 | **不算 D**：正文完整则等级按缺陷定 | **B 级（应修）**，不进「必须修」清单 |

**要点**：附录类缺失一律记 **B 级**并标「挂起·待修」——A 级只留给**影响读者读到内容的**缺陷（漏译、错配、截断、叙事缺失）。附录缺失不阻塞发布，写进修复点即可。

**例外**：附录类缺失若造成**正文内指代悬空**（如译文出现「门上钉着这样一张告示：」而下文没有告示内容），该段按 **A 级**计入。

### B-5. **D 的判据（2026-09-16 定稿，全批适用）**

满足任一条即判 **D 严重·挂起·待修**：

| # | 判据 |
|---|---|
| a | 缺失 **≥10% 段落**（按篇或按书，取其中成立者） |
| b | 缺失构成**整幕 / 整节 / 整篇** |
| c | **多处（≥2 处）章末 / 终场缺失** |
| d | **短篇集或合集内某一篇**的结尾整节缺失（该篇作为独立作品不完整） |

**单处长篇的章末段缺失（不满足 a–d）→ 记 A 级缺陷**，总等级按 A 级数量落 B/C，不判 D。

**B-4 与 B-5 的关系（裁决口径，2026-09-21 明确）**：判 **D 一律以 B-5 的四条判据为准**（2026-09-16 定稿）；B-4 的作用是区分缺陷的**级别**——「叙事与戏剧正文」缺失记 **A 级**，「文献附录类材料」缺失记 **B 级**。不满足 a–d 的零星叙事缺失：记 A 级、总等级落 B/C，**但始终须标「挂起·待修」并列出修复点与复算命令**（读者可见的悬空标点等佐证照写）。若仍属两可，在报告第七节并列两种读法供派发方裁量，不要擅自拔高或压低。

## 五、误报防线（重要，历史误报率高）

1. **先查口径再定性**：`---` 分隔线、章题行、小节标题、诗行断行会把中文段数顶高；段数差先定性口径。
2. **预检残留标记必须核语境**：`车站`（火车站语境合法）、`狐狸`（字面义合法）、`torch`（若全书语境是手电筒则应报器物误译）——**看到计数不等于看到缺陷**。
3. **英文残留≠违规**：首现括注、保留诗行、专名保留、括注内英文都合法。
4. **幽灵条目要验证**：术语表列了但源文 0 次出现的条目（历史第 3 例：`Tarrant`、`Janet`、`Peter McLaughlin`）属**建库期误植**，不得当作硬约束判译者违规——以译文自身多数译法为基准查同名异译。
5. **项目说明可能有错**：简介/备注偶有张冠李戴或体例约定与源文不符，**以实际源文为准**；发现就在报告「元数据备注」记一笔，不要改文件。
6. 发现「译者善意修正原文讹字」（把源文错处改对了）——按历史判例记 **C 级**。

**等级判据（按本库口径）**：
- `A 优秀`：**无 A 级问题** ＋ 数据层五项（块段三方零不对称 / 英文块**词级**逐字一致 / 术语零违规 / 英文残留 0 / 数字全对）＋ 余下瑕疵仅**零星**。
  - **「零星」的明确定义（2026-09-16 第二次修正）**：
    - 英文对照块**语义中性**的损坏（掉/多冠词、功能词、词尾 `-ed/-s` 等，共 **≤3 处**）→ 允许不阻 A，须逐处列明。
    - 单一术语分义项/上下文漂移 ≤1 类。
    - **计数方式：B 级按「合并类」计，≤3 类**（例如同一类问题在多处出现算 1 类）。
    - **语义反转/换词（如 `with→for`）、成片同类蔓延 → 仍落 B**，不受本条豁免。
  - **判据精神（为何 EN 块瑕疵权重低）**：`===Original===` 块是**双语对照的英文镜像**，其字符级小疵不影响中文读者的阅读与交付质量；**A 档要排除的是影响内容的系统性缺陷**。但英文块若被**换词/改义/中文串入**，仍按 B/A 计。
  - **成片即降**：同类问题多处蔓延（如整批换词、术语跨章多形、残留反复出现）→ 落 `B 良好`。
  - 判据精神：A 档排除的是**系统性**数据层缺陷，不是零瑕疵；零星瑕疵如实列在 B 级条目里即可。
- `B 良好`：无 A 级问题，但 B 级**成片**（同一类错误多处蔓延）或含**系统性**错误；或有 1–2 处 A 级而整体质量仍过硬。
- `C 需关注`：A 级若干，或 B 级成片（如跨章异译十几组、系统性器物误译）。
- `D 严重`：成片漏译/整节无译文等结构性缺陷（如章末段+章题诗成片未译、素材截断）。

**产物级缺陷例外**：若发现「未完成产物」特征（分片 `_partN` 晚于主交付物落盘、主交付物覆盖率明显低于分片、块数严重不对等），**不要写等级报告**，改为：取证（mtime 表、覆盖率、复算命令）→ 写进报告并标注 **「挂起·待修」**，在回报中明确上报。

## 七、质量要求（验收标准）

1. 每条 A/B 级必须可被第三方用 `grep` 复现（给出可搜索的原文/译文片段）。
2. A 级一处不漏——尤其**双侧同缺**型（必须逐块比段落数与首尾句，不能只看块数）。
3. 专项①（英文块逐字 diff）**必须给出结论**，哪怕是「零处损坏」。
4. 报告字段齐全（审校日期 / 质量等级 / 一句话结论 三行必须在，供台账解析）。
5. 不写空话套话；「无问题」也要给证据（计数、命令）。
