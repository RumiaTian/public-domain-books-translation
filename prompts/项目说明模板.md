# 项目说明（模板）

> 这是新翻译项目的配置文件模板。开始一个新翻译项目时：复制本文件到项目文件夹，重命名为 `项目说明.md`，填写下方字段。翻译时，agent 会读取本文件 + `prompts/通用翻译引擎.md` + 选定的领域配置 + 术语表（如有）。

---

## 基本信息

- **项目名称**：
- **源语言**：英语
- **目标语言**：中文
- **内容简述**：（一两句，说明这是什么内容，帮助译员把握基调）

## 翻译配置

- **领域配置**：`prompts/领域配置/技术文档.md`
  > 从以下选一：`技术文档.md` / `历史古籍.md` / `学术著作.md` / `小说文学.md`。也可填「通用」（仅用通用引擎，不叠加领域配置）。
- **输出粒度**：逐段对照
  > 两种选择：`逐段对照`（英文段 → --- → 中文段，适合技术/学术）或 `块对照`（原文几段 → --- → 译文几段，适合小说/历史）。各领域配置有默认建议，此处可覆盖。
- **内容形态**：短篇集
  > 从以下选一：`新闻` / `技术文章` / `短篇集` / `长篇` / `中篇`。判据见 `2_翻译WORKFLOW.md`「两大执行模式」——独立成篇或章数多的形态（前四类）走委派模式，单一叙事弧且章数少的「中篇」走连续模式。建项目时 agent 通读全书结构与篇幅分布自主判断。
- **执行模式**：委派
  > 由内容形态自动决定，通常不手填：`委派`（新闻/技术/短篇集/长篇，子代理逐篇译）或 `连续`（中篇，主 agent 直译）。两者共用同一套单篇 9 步流程，区别只在执行者，详见 `2_翻译WORKFLOW.md`「单篇翻译 9 步」。
- **术语表**：无
  > 若有术语表，填文件名（如 `术语表.md`），放在项目文件夹根目录。无则填「无」。

## 文件位置

- **原文位置**：原文/
- **译文位置**：译文/
- **译文命名**：原名.zh-CN.md（放译文目录；并排模式则与原文同目录）
