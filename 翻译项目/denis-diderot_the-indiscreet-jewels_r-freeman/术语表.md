# 术语表（初版）

> 狄德罗《泄密的珠宝》（The Indiscreet Jewels / Les Bijoux indiscrets，R. Freeman 英译本）。人名地名多为狄德罗生造的东方风名字，无通行中文译名，按音译并全书统一；首次出现附原文。书名主词 **Toy（bijoux）** 是全书谐谑核心，译法必须全文一致。

## 翻译策略总注

1. **人名**：无通行译名者按发音音译，全书统一；首次出现标「中文（English）」。名字里的连写长名（如 Brrrouboubou）保留原文的滑稽音感。
2. **罗马数字章号**（I、LI 等）照搬不译，如「第 I 章」写法为「I 曼戈古尔的诞生」→ 标题合并时保留罗马数字原样。
3. **钱币、牌戏名**：音译为主，首次附原文。
4. **谐谑语**：18 世纪荡涤的讽刺笔调（对宗教、学界、宫廷的挖苦）要译出俏皮劲儿，但不用现代网络语。
5. 译文新遇未登记人名时，先查本表，无则按音译规则自定并回填本表。
