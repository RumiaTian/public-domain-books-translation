# 翻译计划（ameen-rihani_poetry）

## 本计划信息

- **项目名称**：ameen-rihani_poetry（《阿明·里哈尼诗集》— Ameen Rihani: Poetry）
- **源文目录**：原文/
- **译文目录**：译文/
- **译文命名**：原名.zh-CN.md（放译文目录）
- **领域配置**：prompts/领域配置/小说文学.md
- **术语表**：术语表.md
- **执行模式**：委派（短篇集：82 个独立单元，子代理逐篇执行下方 9 步）

## 文件分工

| 文件 | 作用 | 谁来改 |
|------|------|--------|
| `项目说明.md` | 项目基本信息、领域配置、诗歌专则 | 人工 |
| `术语表.md` | 翻译硬约束层。每篇译完补充新词 | agent / 人工 |
| `translation_queue.csv` | 任务队列。每行一文件，`file, size_kb, status` 三列 | 翻译前改 doing，完成后改 done |
| `Plan.md`（本文件） | 执行步骤 + 运行日志 | agent 追加日志 |
| `原文/*.md` | 源文（01–82，序号=阅读顺序） | 不改 |
| `译文/*.zh-CN.md` | 译文产出（块对照双语） | 翻译 agent 产出 |

## translation_queue.csv 格式

```
file,size_kb,status
01-dedication.md,0.1,todo
02-salaam.md,2.8,todo
...
```

| 字段 | 含义 | 取值 |
|------|------|------|
| `file` | 源文文件名（在 `原文/` 目录下） | 如 `03-ever-to-be.md` |
| `size_kb` | 源文大小（KB）。全部 <20KB，无超长文 | 数字 |
| `status` | 翻译状态 | `todo` 待译 / `doing` 翻译中 / `done` 已完成 |

## 执行步骤（agent 按此推进，两种模式共用）

### 1. 读配置（每次翻译前必读）
```
1. 本项目 Plan.md（本文件）
2. 项目说明.md（含诗歌翻译专则）
3. 术语表.md
4. prompts/通用翻译引擎.md
5. prompts/领域配置/小说文学.md
6. 译文/ 下任意一篇已完成的 .zh-CN.md（作为风格黄金样本，照此风格译；无则跳过）
```

### 2. 取任务
读 `translation_queue.csv`，取第一个 `status=todo` 的行。先 `ls 译文/` 检查该篇译文是否已存在：
- 已存在 → 直接改 `done`，跳到步骤 8。
- 不存在 → 把该行 `status` 改为 `doing` 并保存 CSV，继续。

### 3. 读源文
读 `原文/对应文件名`。

### 4. 翻译
产出到 `译文/对应文件名去.md加.zh-CN.md`。

- 双语对照格式、标记规则、完整性禁令见 `prompts/通用翻译引擎.md` 第五、六节。
- **诗歌专则**（项目说明.md「备注」）：每首诗一块、块内逐行对应、诗节空行保留、押韵尽量再现、拟人化大词按术语表。
- 严守术语表；新词自行确定统一译法，首次附原文「中文（English）」，并回填术语表。

### 5. 自检
- 完整性：源文每一诗行都在译文 Original 块中出现，末尾无截断。
- 块对称：Original/Chinese 数量相等，每块内行数对应。
- 标题格式：全部「英文 / 中文」合并；罗马数字、尾注标记照搬。
- 术语一致：抽查 5 个术语词，全文译法统一。
- 不满足则改到满足。

### 6. 自动检查
```
python scripts/check_bilingual.py 译文/对应篇名.zh-CN.md
```
通过则继续；有违规回步骤 4 修订。

### 7. 回填状态（双写）
`status` 从 `doing` 改 `done`，改两处：
- ① 项目 `translation_queue.csv` 该行；
- ② 根 `translation_queue.csv` 中 `<ameen-rihani_poetry>,<本篇名>` 那一行。

### 8. 追加日志
在本文件「运行日志」追加一行。

### 9. 循环
回到步骤 2，取下一篇 `todo`，直到全部 `done`。
