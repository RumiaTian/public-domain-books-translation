# 术语表

> 《巴拉阿姆与约阿萨弗》（*Barlaam and Ioasaph*， Woodward & Mattingly 英译本）专有名词与术语。首次出现附原文「中文（English）」，后文统一用中文译名。
>
> **译名策略**：
> - **圣经人名地名循和合本**：本书英译刻意仿钦定本圣经，圣经共有人名/地名（Thomas、Senaar 等）一律采用和合本定译，保证语体统一。
> - **非圣经人名**（故事角色 Barlaam、Abenner、Nachor 等）按通行音译，全书统一；主角名 Ioasaph 采「约阿萨弗」（即西传之 Josaphat 约萨法特，名源 Bodhisattva/菩萨）。
> - **宗教术语**（修院、教义、礼仪）用天主教/东正教通行中译；三位一体、基督论术语依大公教会规范译法。
> - **罗马数字**章节序号照搬不译；**希腊语引文**照搬不译；度量衡与货币（talent 他连得、hecatomb 百牛祭等）依和合本/规范译法。
> - 原文古雅语体（thou/hath/-eth）以和合本式庄重书面语体对应，不用现代口语。

## 人物表

| 原文 | 译名 | 说明 |
|------|------|------|
| Barlaam | 巴拉阿姆 | 西奈来的隐修士，约阿萨弗的灵性导师（St. Barlaam；或作巴拉姆，本表统一巴拉阿姆） |
| Ioasaph | 约阿萨弗 | 主角：印度王子，后皈依、弃位修道（即西方之 Josaphat；名源 Bodhisattva） |
| Abenner / Abenes | 阿本内尔 | 印度王，约阿萨弗之父，初为迫害者，终皈依（变体拼法 Abenes 亦统一此译） |
| Nachor | 纳霍尔 | 行幻术的智者，貌似巴拉阿姆，被推冒名赴御前辩论；其「辩词」实为阿里斯提德《护教文》 |
| Theudas | 特乌达斯 | 巫师，向王献美色之计（和合本《使徒行传》5:36 同名者作「丢大」，此为故事角色，循希腊形音译） |
| Araches | 阿拉凯斯 | 王的首席谋臣 |
| Zardan | 扎尔丹 | 总督/太傅，受命抚育约阿萨弗 |
| Barachias | 巴拉加 | 约阿萨弗挚友，继任印度王，迎回二圣遗体（循和合本《马太福音》23:35 Barachiah「巴拉加」） |
| Thomas | 多马 | 基督十二使徒之一，首传福音至印度（和合本译法） |
| Aristides | 阿里斯提德 | 雅典哲学家，2 世纪《护教文》作者（见序言） |
| St. John of Damascus | 大马士革的圣约翰 | 本书传统署名作者，8 世纪教父（序言考辨） |
| Buddha | 佛陀 | 序言论及的故事东方蓝本 |
| King Abenner's astrologers | 占星家 | 预言王子命运者，非专名，照常语译 |

## 地名表

| 原文 | 译名 | 说明 |
|------|------|------|
| India / the Indians | 印度 / 印度人 | 书中「印度」泛指东域，自谓故事得自「埃塞俄比亚内陆」之人；照书名惯例作印度 |
| the inner land of the Ethiopians | 埃塞俄比亚内陆 | 导言中故事的传来地 |
| Persia | 波斯 | 与「印度」接壤 |
| Egypt | 埃及 | 修院运动发源地 |
| desert of Senaar | 示拿旷野 | 巴拉阿姆隐居之地；循和合本 Shinar「示拿」（创 10:10） |
| Jerusalem | 耶路撒冷 | 圣经地名 |
