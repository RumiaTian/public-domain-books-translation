# 术语表（杰克·基夫故事集 / The Jack Keefe Stories）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **核心文体：书信体+满纸错别字的第一人称口语**。杰克把 series 写成 serious、male=mail、stumick=stomach、onct=once、tho=though、1/2 数字混用等，是无知自大的标志笑料。中文不逐字仿造错别字（易读性崩坏），改用：① 口语絮叨、成分残缺、文理欠通的句式；② 关键讹词首次出现时括注原文（如「世界大赛（world serious）」）；③ 事实性口误（人名记错、常识错误）照实直译保留笑点。
- **书信落款**统一：`Your pal, / **Jack**.` → 「你的老伙计，**杰克**。」；称呼 `Friend Al` / `Dear Friend Al` / `Old Pal` → 「艾尔老伙计」/「亲爱的艾尔老伙计」/「老伙计」。
- **棒球专名**：球队通用通行译名（白袜、老虎、扬基、红袜等）；人名音译，首次附原文；现实棒球名人（Comiskey、Walter Johnson、Babe Ruth 等）用通行译名。
- 罗马数字、比分、金额、日期缩写（Sept. 23 等）照搬不译。
