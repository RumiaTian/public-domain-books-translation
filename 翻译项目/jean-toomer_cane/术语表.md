## 方言与语言策略

| 源词 | 译法 | 说明 |
|------|------|------|
| Black dialect (Southern vernacular) | 口语化汉语，保留粗粝感 | 黑人南方口语（如 cant / aint / foh / th）不逐字硬仿，用简短、不规范但可读的汉语口语再现，避免丑化腔调 |
| White Southern speech | 带优越感的官话口语 | 白人南方话语（如 nigger 等蔑称）按语境译"黑鬼/黑崽子"等，保留时代残酷性，不淡化 |
| O cant you see it | 哦，你难道看不见 | 歌谣叠句，保持重复与节奏 |
| double vocatives (O...) | 哦…… | 抒情呼语保留 |
| yassur / nassur | 是哩，老爷 / 不哩，老爷 | 黑人南方口语应答（Fern、Cotton Song） |
| hant | 阴魂 | 方言 haunt（Becky 篇） |
| Gedap | 得儿驾 | 赶牲口口令 giddy-up（Carma 篇） |
| agwine t / Ise gwine t | 俺要…… | 方言 going to / I'm going to，用粗粝口语再现 |
| CM / EOD 等缩写（如有） | — | 本书原文基本无缩写术语 |

## 诗歌翻译策略（备注）

- 各篇开篇/插入的诗歌与歌谣（如 "Her skin is like dusk…"、"Reapers"、"Cotton Song"、"Song of the Son"、"Harvest Song" 等）**必须保留原有诗行结构与分行**，一行对一行翻译，不合并、不散文化。
- 引文块（>）与缩进保持原样；叠句重复处译文同样重复。
- 韵脚无法全保时优先保住意象与节奏（短句、顿数相近）。
