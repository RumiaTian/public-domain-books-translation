## 地名 / 天体

| 原文 | 译法 | 说明 |

| Tormance | 托曼斯 | 音译（大角星旁的行星，Arcturus 与 torment+romance 合成词） |

| Swaylone's Island | 斯韦隆之岛 | 音译+意译 |

## 哲学 / 专有概念

| 原文 | 译法 | 说明 |
|------|------|------|
| Muspel-fire | 穆佩尔之火 | 终极精神实在的火焰 |
| back rays | 回射之光 | 意译（Muspel 向回投射的光，与 forward rays「顺射之光」相对） |
| forward rays | 顺射之光 | 意译 |
| Crystalman's world | 晶人的世界 | 感官/欲望构成的表象世界 |
| Faceny | 费森尼 | 晶人在 Tormance 的化身名之一，音译 |
| Amfuse | 阿姆菲尤斯 | 晶人化身名，音译 |
| Kree | 克里 | 晶人化身名，音译 |

| shaping | 塑形 | 书中哲学关键词（创造/塑造之力），意译 |
| sensual pleasure / pleasure | 感官之乐 / 快乐 | 哲学对立概念，按语境统一 |

| torlyfe | 托利夫 | 音译（Tormance 语言中的「生命」） |
