# 术语表（民主与社会伦理）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。本书为简·亚当斯（Jane Addams）1902 年出版的社会学经典，是社会伦理学与进步主义改革运动的奠基文献之一，核心概念（民主、社会伦理、慈善关系、睦邻运动术语）务必全书统一。

## 翻译策略

- **核心概念定译**：social ethics = 社会伦理（书名核心词，全书统一），Democracy = 民主（大写首字母的哲学概念亦同），social morality = 社会道德（区别于 personal/individual morality = 个人道德），the social claim / social obligation = 社会性诉求 / 社会义务，the democratic impulse = 民主冲动。
- **睦邻运动术语**：settlement house / social settlement = 睦邻公社（19 世纪末英美社会改革运动机构，通行译法，不译「定居点」），settlement = 睦邻公社（指机构时），Hull House / Hull-House = 赫尔会所（通行译名，作者 1889 年在芝加哥创立的睦邻公社），settler / resident = 驻舍居民（指入住睦邻公社的 reformer），the neighbourhood / neighborhood = 街坊／邻里（按语境）。
- **慈善运动术语**：charitable effort = 慈善活动（章名 Charitable Effort 亦同），charity / charitable relation = 慈善／慈善关系，benefactor = 施惠者，beneficiary = 受惠者，philanthropy = 慈善事业，philanthropist = 慈善家，social compunction = 社会良知之刺痛（filial-relations 章关键概念），relief = 救济，friendly visitor = 友善访问员（慈善组织会（COS）术语，如出现）。
- **政改术语（political-reform 章）**：the boss / political boss = 政治「老板」，the gang = 帮派（依附于 boss 的政治小集团），ward = 选区，alderman = 市参议员／市议员（统一用「市议员」），office holder = 官职把持者／公职人员（按语境），municipal ownership = 市有制（市政公有），civic = 市民的／公民的（按语境统一），civil service = 文官制度（regulations＝文官条例、law＝文官法），political machine = 政治机器，reform movement = 改革运动，constituents = 选民，franchise = 特许权（streetcar franchise＝电车特许权），city council = 市议会，boodler = 贪贿者（champion boodler＝头号「贪贿大王」），Con Row = 「骗子街」（选区内成功政客聚居街的诨名），craps = 掷骰子，push = 帮伙，slot machine = 老虎机，temperance brigade = 少年禁酒队，Great Experience = 「大经验」（指死亡）。
- **劳工与教育术语**：trades-union / trade union = 工会，trades-unionist = 工会议员／工团主义者（按语境，指一般会员译「工会会员」），industrial amelioration = 产业改良，sweating system = 血汗工制（如出现），University Extension / university extension centres = 大学推广教育（中心），Child Study = 儿童研究，night school = 夜校，business college = 商业学院，padrone = 包工头（意大利移民劳工中介），mechanic institute = 机械工人讲习所，industrial education = 产业教育，stereopticon = 立体幻灯，normal school = 师范学校，Woman's Clubs = 妇女俱乐部（educational-methods 章用）。
- **家务劳动术语（household-adjustment 章）**：household employee / domestic employee = 家务劳动者，household employer / employer of household labor / employer of domestic service = 家务雇主，household labor = 家务劳动，domestic service = 家务服务，personal service / personal ministration = 人身侍奉，mistress and servant = 女主人与女仆（泛称「主仆」），tenement house = 廉租公寓，residence clubs = 寄宿俱乐部，esprit de corps = 团体精神，globus hystericus = 癔症球，"unconscious slavery" = 「无意识的奴役」。
- **产业改良章术语（industrial-amelioration 章）**：associated effort / associated action = 联合努力／联合行动，model town = 模范城镇，nonunion shop = 非工会工厂，sympathetic strike = 同情罢工，arbitration = 仲裁，American Railway Union = 美国铁路工会，one-man rule = 「一人统治」，public trust = 公众信托，mutual benefit association = 互济会，factory legislation = 工厂立法，child-labor law = 童工法，"industrial betterment" = 「产业改善」（与章名 industrial amelioration＝产业改良区别），Referendum = 公民投票。
- **人名译法**：见下方人物表，首次出现标「中文译名（原名）」，后文用中文译名。
- **刊物名**：The Atlantic Monthly = 《大西洋月刊》，The International Journal of Ethics = 《国际伦理学杂志》，The American Journal of Sociology = 《美国社会学杂志》，The Commons = 《公地》（The Commons，睦邻运动刊物，无通行译名，首译附原文）。
- **罗马数字章号**：正文标题自带罗马数字（## II Charitable Effort），照搬不译，如「## II 慈善活动（Charitable Effort）」按引擎标题合并规则处理。
