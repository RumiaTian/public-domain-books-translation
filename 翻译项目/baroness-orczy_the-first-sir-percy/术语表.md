# 术语表（初版）

> 依据：通读第 1、2、6、14 章 + 结尾章（17）及全书专名频次统计。翻译时遇下列源词，译法必须统一。新词随译随补。

## 翻译策略

- **人名**：英/荷人名按通行译名表音译，首次出现附原文「中文（English）」。昵称、称谓单独列条。
- **哲人诨名**：Diogenes / Socrates / Pythagoras 是男主及其伙伴的化名，取希腊哲人通行译名（第欧根尼/苏格拉底/毕达哥拉斯），首次出现附原文。
- **地名**：尼德兰地名用通行译名（阿默斯福特、乌得勒支、奈梅亨等）；小地名（巴讷费尔德、沃尔登等）按音译并首现附原文。荷兰语旧拼法（Arnheim、Neder Rhyn、Zuyder Zee）按今通行名译出（阿纳姆、下莱茵河、须德海），不保留旧拼。
- **荷兰语尊称**：Mynheer / Mevrouwe / Jongejuffrouw 意译为「老爷（先生）/ 夫人 / 小姐」，首次出现附原文；行文中按语境可作「老爷」「夫人」。
- **拉丁语**：Mala Fides 等拉丁短语保留原文并括注意译（背信），章题可意译附原文。
- **历史专名**：Stadtholder 译「执政」（首现附原文），即联省共和国执政（奥兰治亲王）；United Provinces 译「尼德兰联省共和国」（简称「联省」）。
- **货币**：guilder 音译「盾」不换算。
- **罗马数字章号**：大章题罗马数字（## I 等）与小节号（### I / ### II…）照搬不译。
- **年代与史实**：1624 年、八十年战争背景照实译；真实历史人物（拿骚的莫里斯、大公夫人伊莎贝拉、弗兰斯·哈尔斯）用通行译名。
- **同系列一致性**：本书主角即「猩红繁笺花」先祖，凡涉 Blakeney / Scarlet Pimpernel 之名，与项目 `baroness-orczy_sir-percy-hits-back` 术语表保持一致。
