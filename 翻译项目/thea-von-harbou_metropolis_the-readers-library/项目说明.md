# 项目说明

## 基本信息

- **项目名称**：大都会（特娅·冯·哈堡）
- **源语言**：英语
- **目标语言**：中文
- **内容简述**：德国作家特娅·冯·哈堡（Thea von Harbou）1925 年的长篇科幻小说《大都会》（Metropolis），亦为 1927 年弗里茨·朗同名电影的原著。在两极分化的巨型未来之都大都会中，统治者的儿子弗雷德尔邂逅工人的精神领袖玛丽亚，目睹地下机器大厅的苦难与机器人的阴谋；在毁灭性的洪水与暴动之后，「大脑」（统治者）与「双手」（工人）终需由「心」来调停。全书分 25 章（罗马数字 I–XXV）加作者题词，单一叙事弧，约 6.4 万词。

## 备注

- 书名定为《大都会》，沿用 1927 年弗里茨·朗同名电影与小说的通行中译名（备选：《繁华大都市》，不取）。
- 原文为 Standard Ebooks / Reader's Library 制作，正文已按 spine 顺序分章提取：00-preface（作者题词）+ 01-i 至 25-xxv（罗马数字章节）。原文件名为小写罗马数字（i.md … xxv.md），无阿拉伯数字，会导致自然排序错乱（i, ii, iii, iv, ix, v…）；故已统一加两位数字前缀（00–25）以保证阅读顺序，罗马数字原貌保留在前缀之后（如 `09-ix.md`）。
- 章节内标题为 `## I` … `## XXV`（大写罗马），译时按通用引擎规则合并为「英文 / 中文」标题（如 `## I / 一` 或保留罗马 `## I / I`，见术语表策略——罗马数字章号照搬不译，故章号 I–XXV 不译，标题作 `## I / I`）。
- 德语专名（Joh Fredersen、Rotwang、Yoshiwara 等）及机器人命名（Futura / Parody）、主题意象（大脑—双手—心 / 调停者）的统一译法见术语表.md。
