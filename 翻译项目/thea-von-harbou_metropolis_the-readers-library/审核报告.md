## 七、等级判定理由

- **A 级（必须修）＝ 0 处**：语义错配、整段漏译、章末截断、重大数字错译四项全零，专项③（双侧同缺）经逐块跨度核验为零，故不触发任何 A 级判据，也**不存在** B-5 的 a/b/c/d 任一条（无 ≥10% 段缺失、无整节/整幕/整篇缺失、无 ≥2 处章末缺失、无短篇结尾整节缺失）。**未出现「未完成产物」特征**：26 篇全部落盘且 mtime 同批（阶段三前最后一次写入为 09-18 18:26），无 `_partN` 分片，无 `.all.zh-CN.md` 合并产物混入，主交付物覆盖率与分片一致故不适用。
- **为何不是 A 优秀**：A 档五条数据层硬指标中，「块段三方零不对称／英文块词级逐字一致／英文残留 0／数字全对」**四条全满足**（英文块甚至是字节级完全一致，为本批次少见的干净），但**「术语零违规」不满足**——存在 3 类术语违规/跨章异写（Huitzilopochtli、gargoyle、drink-mixer）。按判据，A 档要求术语零违规，故不能给 A。
- **为何是 B 良好而不是 C**：缺陷集中在术语层，且**每一处的内容本身都是正确的**（「惠齐洛波契特里」确为该神名的可读音译、「滴水嘴兽」确为 gargoyle 的通用译名之一、「调饮姑娘」字面即 drink-mixer），不存在语义错误或读者读不到的损失；B 级仅 3 合并类、7 处，未达「跨章异译十几组」「系统性器物误译」的 C 档量级；余下 9 项均为体例/排版/字面可读性层面的 C 级建议。按判据「B 良好＝无 A 级问题，但 B 级成片（同一类错误多处蔓延）或含系统性错误」，而「术语跨章多形」正是判据点名的 B 档触发项，故定 **B 良好**。
- **未触发 D**：无成片漏译、无整节无译文、无素材截断；专项⑥「缺失 0 段」、专项⑦最低译率 0.33，交付物内容完整。
