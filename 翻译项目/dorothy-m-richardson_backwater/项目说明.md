# 项目说明

## 基本信息

- **项目名称**：《回水》（多萝西·米勒·理查森）/ Backwater (Dorothy M. Richardson)
- **源语言**：英语
- **目标语言**：中文
- **内容简述**：本书是英国作家多萝西·米勒·理查森《朝圣》（Pilgrimage）十三卷序列的第二部（Standard Ebooks 元数据 group-position 2；1916 年初版），最早的意识流小说代表作之一。延续主人公米丽亚姆·亨德森的内心历程：自汉诺威返英后，刚满十八岁的她受聘于北伦敦郊区"班伯里公园"珀恩三姐妹开办的女子学校，以每年二十镑的薪水教低年级、照管四名寄宿生。全书以贴紧米丽亚姆意识的自由间接引语，铺陈她对"北伦敦"庶民世界的隔岸观察、对珀恩三姐妹旧式淑女风度的沉迷、对学校日常（点名、餐桌、读物的匮乏）的细察，穿插巴恩斯家中的花园晚会与河上泛舟、对青年特德的隐秘情愫、布莱顿度假时姐姐伊芙身边的追逐者，以及爱尔兰见习教师朱莉娅·多伊尔的到来带来的冲击，最终在年度颁奖礼上告别学校。郊区岁月如"回水"（backwater）——停滞的侧流——静静旋绕，叙事绵延流动、感官印象密集、内心独白与思绪跳跃贯穿始终。

## 备注

- 全书 10 章（罗马数字 I–X），单一连续叙事弧（米丽亚姆在班伯里公园学校任教约两年间的日常与内心历程）。章数 ≤15 且不可分割的整体 → 中篇 → 连续模式。全书约 30.7 万字节，主 agent 连续翻译单批受上下文限制，可分批推进。
- 与姊妹项目《尖顶屋》（卷一）直接衔接（本书自汉诺威返英开场），共享主人公米丽亚姆·亨德森、亨德森家族与杰拉尔德等人物及意识流语体。人物、地名、翻译策略须与《尖顶屋》《过渡》《僵局》术语表保持一致；本书术语表已沿用其家族译名。
- **核心风格约束**：意识流。译文必须保留米丽亚姆内向、反思、跳跃的意识语体——大量自由间接引语、省略号（……）、破折号、片段式短语构成思绪的绵延与断流，不可"理顺"为平铺直叙的外视角叙述。详见术语表"翻译策略"。
- **珀恩姐妹的旧式口音**：三姐妹说话带轻微的旧派北部腔与老小姐用语（yerself / ye've done / M'yes / gels〔=girls〕/ "Oh—er—hee—hay"），中文以温软古旧、絮絮低回的老妇人语气传达，不用方言字；gels 等变读词首次出现括注。详见术语表。
- 文中穿插少量法语（la reine、au revoir）与德语（Klassische Stücke、Mit Frauen spreche ich überhaupt nicht）：有标识性的保留原文并紧跟中译，日常短句径直译出。
- "North London"（北伦敦）是贯穿全书的社会学意象（与米丽亚姆所来自的巴恩斯中产世界相对），全文统一译"北伦敦"，保留其阶级观察的锋芒。
- 章节标题为罗马数字 I–X，照搬不译；源文文件已统一命名 chapter-1.md…chapter-10.md（罗马数字文件名会乱序）。
