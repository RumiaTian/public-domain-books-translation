# 术语表（我的光辉生涯）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。
> 本书为澳大利亚作家迈尔斯·富兰克林（Miles Franklin）1901 年出版的自传体成长小说《我的光辉生涯》（My Brilliant Career）。叙述少女西比拉·梅尔文（Sybylla Melvyn）自幼年随父在牧场上野性生长，到家境败落后迁居袋熊谷（Possum Gully）饱尝贫苦，又被送往卡达加特（Caddagat）外祖母家与哈罗德·比彻姆（Harold Beecham）相遇，几经周折终不愿屈从婚姻、矢志成为作家的始末。本表为建项目时据前言、引言、首尾及若干中段样章整理的初版，译员译毕各篇后自行补充新词。

## 翻译策略

- **书名**：*My Brilliant Career* 译《我的光辉生涯》（含反讽意味——"career"既指父亲赌博式投机"事业"的速败，也指西比拉自身人生道路）。全书书名与各章章名中的 career 一词须视语境处理。
- **叙述视角与人名**：全书为西比拉第一人称自述。主要人物通行音译，首次出现附原文「中文（English）」，后文统一用中文译名。Sybylla 译「西比拉」（勿译「西比拉」之外的异写）；昵称 Syb 等照应亲昵口吻。
- **亲属称谓**：外祖母（grannie）译「外婆」（首次括注 Grannie）；aunt Helen 译「海伦姨妈」；uncle Julius 的绰号 uncle Jay-Jay 译「朱利叶斯舅舅」，绰号「杰杰舅舅」（Jay-Jay）首次括注。父系兄弟 Horace、Stanley 译「弟弟」（西比拉之弟）；妹妹 Gertie 译「格蒂」，Aurora 译「奥罗拉」（小妹）。
- **绰号／昵称**：父亲 Richard Melvyn 绰号 "Dick" 译「迪克」（理查德·迪克·梅尔文）；uncle Julius 的绰号 Jay-Jay 译「杰杰」；old Dart 为一匹马名（老达特）。
- **地名**：澳大利亚地名用通行译名或音译并首次括注。Possum Gully 译「袋熊谷」（Possum=possum 负鼠／袋熊类，Gully=沟壑／山谷；本书首译「袋熊谷」并括注原文）；Caddagat、Bruggabrong、Bin Bin、Five-Bob Downs、Yabtree、Gool-Gool、Barney's Gap、Cummabella 等牧场景观名音译并括注。Goulburn 译「古尔本」、Sydney 译「悉尼」、Melbourne 译「墨尔本」、Riverina 译「里弗赖纳」（新南威尔士州西南部农业区）、Murrumbidgee 译「马兰比吉」（河名）。
- **澳洲丛林／牧场词汇（全书高频，须前后一致）**：
  - **station** 译「牧场」（大型畜牧场，非"车站"）；**run** 译「放牧地／牧区」；
  - **squatter / squattocracy** 译「大牧场主／牧场主阶层」（占有大片公有牧地的富裕牧主，非"擅自占地者"）；
  - **selector** 译「选地农」（依《选地法》认领小块土地的自耕农）；
  - **jackeroo** 译「牧场学徒」（在牧场学习业务的年轻白人男子），首次括注原文；
  - **boundary-rider** 译「巡栏员」（巡视维修牧场围栏者）；**drover** 译「赶牲口人／驱畜人」；**bullocky** 译「赶牛车人」；
  - **rouse-about** 译「牧场杂工」；**swaggie / swagman** 译「背囊流浪汉／流浪工」；
  - **dingo** 译「澳洲野犬」；**duffer** 译「盗畜贼」（偷盗他人牲口者）；
  - **poddies / poddied** 译「牛犊／手喂（牛犊）」（见书末注释）；**shout / shouting** 译「请客（买酒）」（见书末注释）；
  - **stock-whip** 译「牧鞭」；**stockman** 译「牧工」。
- **度量与货币**：acre（英亩）、mile（英里）、pound（镑）、shilling（先令）、guinea（基尼）等照通译，首次括注；罗马数字章节号（I–XXXVIII）按纯罗马数字规则合并标题「英文 / 中文」。
- **文学典故**：西比拉熟读的澳洲诗人——Gordon（戈登）、Kendall（肯德尔）、Lawson（劳森，即作序的亨利·劳森）、Paterson（帕特森）——及英伦作家 Byron（拜伦）、Thackeray（萨克雷）、Dickens（狄更斯）、Longfellow（朗费罗）等用通行译名；the *Bulletin* 译《公报》（澳洲著名刊物）。
- **风格**：富兰克林文笔热烈、坦率、富于丛林气息与少女的叛逆激情，时而抒情、时而辛辣自嘲。西比拉独白须传达其桀骜、敏感与对庸俗生活的强烈反感；丛林人物（M'Swat 一家、赶车人、流浪汉等）的口语保留粗粝乡土味（包括彼得·麦斯沃特父子被刻意拼写的蹩脚发音如 "gu-r-r-r-l"、"prawperty"、"ev"=of、"yuz"=you 等，译时以相应汉语口语／错字风味体现）；Caddagat 上流场景（外婆、海伦姨妈、比彻姆家）对白则文雅克制。全书基调是对女性命运与艺术抱负的炽热抗争，须把握成长小说的情感张力。
