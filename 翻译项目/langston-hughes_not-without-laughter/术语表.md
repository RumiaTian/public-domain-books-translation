# 术语表（不是没有笑）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **书名**：*Not Without Laughter*（1930）译《不是没有笑》。书名典出休斯自述的创作意图：黑人的生活里有泪水，但"也不是没有笑"。全书以男孩桑迪的成长串起美国中西部小城斯坦顿一个黑人家庭三代人的命运，是哈莱姆文艺复兴的奠基性长篇。
- **方言与对白（核心难点）**：黑人角色（尤其老一辈如黑格外婆、怀特赛德姊妹）大量使用非裔美式英语（AAVE）口语拼法：*de / dis / dat / chillen / yo' / gwine / sho / Lawd / ma / mo' / 'bout / ain't /I's / you's / ’stead / fo'* 等。这是全书声音的灵魂。处理策略参考本库 rudolph-fisher_the-walls-of-jericho 项目：用一致、温暖、带乡土市井气的口语化汉语传达其节奏与身份感（如"俺""娃儿""晓得""天主啊"级别的语域），避免书面腔；勿逐字"译"方言为怪异汉字讹音，而以口语用词、语气词、句式传神。老一辈（黑格、怀特赛德、洛根）乡土腔最重；安吉、坦皮、哈丽雅特等中青年口语较平；白人角色用平直标准语以示对照。人物唱词、布道、哭丧呼喊等韵文段落保留节奏与重复结构。
- **种族用词**：*nigger / nigger* 类词全书高频，须按说话人身份分档：黑人之间自称、互称（含亲昵、自嘲、感慨）译「黑人／黑人们／咱们黑人」，语气粗粝处可作「老黑」；白人嘴里说出（轻蔑、歧视语境，如白人砖匠拒与吉姆博伊同工、酒吧驱逐哈丽雅特事件）如实译「黑鬼」，保留刺痛感。*darky* 同理。*yaller / yellow*（浅肤色）译「浅肤色／黄皮肤」，是书内肤色等级议题关键词。*white folks* 统一译「白人」，感叹语 *White folks sure is a case!* 类保留讥诮语气（「这些白人可真是活宝！」）。
- **人名**：主要人物通行音译，首次出现附原文「中文（English）」，后文统一用中文。教堂称谓 *Sister / Brother*（教友互称，非亲属）译「姊妹／弟兄」（如 Sister Whiteside 怀特赛德姊妹）；*Aunt / Uncle* 对非亲属老人是尊称，译「大婶／大叔」类；本书 Aunt Hager 实为桑迪的外婆，社区惯称 Aunt，统一译「黑格外婆（Aunt Hager）」，旁白中 *his grandmother* 亦同指。
- **地名**：堪萨斯小城 *Stanton*（虚构）译「斯坦顿」；*the Bottoms*（城边黑人贫民区）译「洼地区（the Bottoms）」；*Hickory Woods*（帐篷布道会林地）译「山核桃林」；*Kansas City*「堪萨斯城」、*Chicago*「芝加哥」、*St. Louis*「圣路易斯」、*Omaha*「奥马哈」、*Wichita*「威奇托」用通行译名；*Pearl Street*「珀尔街」、*Penrose Street*「彭罗斯街」音译。
- **宗教用语**：浸信会 *Baptist*「浸信会」、圣公会 *Episcopal*「圣公会」；*moaner's bench*（祷告席上未"得救"的哀哭者座位）译「哀哭席（moaner's bench）」并首次括注；*shout*（圣灵感动下的呼喊舞蹈）译「呼喊舞／喊灵」首次括注；*the Lawd*＝the Lord，方言腔译「主啊／天主啊」随人物口吻；布道章（Beyond the Jordan）的地狱天堂意象保留原文呼喊节奏。
- **机构与专有名词**：*Stanton County Country Club*「斯坦顿县乡村俱乐部」；共济会式黑人社团 *The Royal African Knights and Ladies of King Solomon's Scepter* 译「皇家非洲骑士与所罗门王权杖女士会」；*Emancipation celebration*「解放纪念日庆典」；门肯 *H. L. Mencken*、杜波依斯 *Du Bois*、加维 *Garvey* 等真实人名用通行译名并括注；报刊 *The Chicago Defender*《芝加哥捍卫者报》。
- **音乐与布鲁斯**：全书贯穿布鲁斯、工作歌、爵士（哈丽雅特终成 "Princess of the Blues"）。歌词照录原文于译文内译出（韵文风格），曲名、歌手绰号（如 *Princess of the Blues*「布鲁斯公主」）按篇章语境处理；*blues* 统一译「布鲁斯」。
- **货币与计量**：*dollars* 译「美元／块」随口吻；*ten dollars and costs*（法庭判罚）「罚款十美元加诉讼费」。
