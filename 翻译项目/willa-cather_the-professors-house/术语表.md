## 译法策略

- **the Professor / St. Peter**：译「教授」「圣彼得」。书名 the Professor's House = 教授之屋。
- **Outland**：双关——既是 Tom 的姓氏（奥特兰），又字面意为"外地/异域"，暗示 Tom 是来自西部的"异乡人"。译音译"奥特兰"，必要时注释其象征。
- **the new house / the old house**：新宅 / 旧屋——全书空间对立的核心，译法统一。
- **the attic study / the workroom**：顶楼书房 / 工作间——教授的精神堡垒。
- **turquoise set in silver**：镶嵌在银子里的绿松石——题词核心意象，统一译法。
- **Outland vacuum / the Outland engine**：奥特兰发动机（Tom 的发明）。
- **dollars / cents**：美元 / 美分。
- 学术头衔：Professor / Doctor / Father / Mr. = 教授 / 博士 / 神父 / 先生。
- Cather 长句多但节奏明晰，翻译时保留其从容的节奏，不宜过度拆碎。
