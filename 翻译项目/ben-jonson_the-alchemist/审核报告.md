## 总体评价

质量等级：B 良好

一句话结论：全剧译文才气纵横、神采飞扬，早期现代英语的倒装句法、粗口咒誓、炼金术黑话及骗术机锋还原得淋漓尽致，人物台词极具舞台张力与性格色彩，专有名词与拉丁语/伪西班牙语括注严谨规范；但第五幕末尾因源文提取截断遗漏了全剧最重要的终场诗（Epilogue）及终场前独白（A 级），且开场诗有 1 处将动词 "better" 误读的反向误译（B 级），补齐并修订后即可达到 A 级典范水平。

略加优容，

## 术语一致性检查

全书严格对照《术语表.md》核查，一致性表现极其优秀：

1. **核心人物表全剧统一**：
   - Subtle -> 萨特尔（自称与他称均严格对应"博士"）；
   - Face -> 费斯（对外称"队长"，末幕被主人当面称本名"杰里米/Jeremy"）；
   - Dol Common -> 多尔·康门（昵称多尔、杜莎贝尔，假扮仙后与贵妇）；
   - Dapper -> 达珀；
   - Abel Drugger -> 亚伯·德拉格（外号纳布/Nab、肺哥/Lungs）；
   - Lovewit -> 洛维特；
   - Sir Epicure Mammon -> 伊壁鸠鲁·玛蒙爵士（通称玛蒙爵士）；
   - Pertinax Surly -> 珀蒂纳克斯·瑟利（瑟利，化身堂迭戈）；
   - Tribulation Wholesome -> 特里比尤莱申·惠尔萨姆（惠尔萨姆牧师）；
   - Ananias -> 亚拿尼亚（亚拿尼亚执事）；
   - Kastril -> 卡斯特里尔（好斗的少年）；
   - Dame Pliant -> 普莉恩特夫人；
   - 邻人甲至己、官差甲乙等群像编号完全一致。

2. **专有名词与炼金黑话**：
   - philosopher's stone / Stone -> 哲人石 / 石头；
   - elixir -> 灵药；
   - projection -> 投射（点金）；
   - multiplication -> 倍增；
   - transmutation -> 嬗变；
   - casting figures -> 排盘起数；
   - horoscope -> 星命盘；
   - familiar -> 侍灵；
   - Queen of Fairy -> 仙后；
   - humours -> 癖性；
   - silenced saints -> 被禁声的圣徒；
   - Anabaptist -> 再洗礼派；
   - angel -> 安琪尔金币（全剧涉及货币处均统一，占星/宗教语境中准确依义译为善星/天使）。

3. **外语保留与括注**：
   - 炼金拉丁语 `aurum potabile`（可饮之金）、`lapis philosophicus`（哲人石）、`equi clibanum`（马炉之热）、`magisterium`（大匠秘药）、`ad infinitum`（以至无穷）、`sanguis agni`（羔羊之血）、`homo frugi`（节俭自持之人）等均严格照搬并附标准括注；
   - 第四幕瑟利假扮西班牙贵人时的大段西班牙语（*Señores, beso las manos a vuestras mercedes.* 等）均按规范保留原斜体并在其后括注完整中文对译。

4. **度量与货币核验**：
   - 4 angels -> 四枚安琪尔金币、40 marks -> 四十马克、20 nobles -> 二十来枚诺布尔金币、1 crown -> 一枚克朗、1 portague -> 一枚葡萄牙金币、5000 pounds -> 五千镑、10000 pounds -> 一万镑、600 and 10 -> 六百一十年等，数字与币种全部精确对应，无硬伤。

## 亮点示例

1. **第一幕开场对骂（萨特尔 vs 费斯 vs 多尔）**：
   节奏极紧，市井粗鄙与炼金术隐喻交织（「你这屎壳郎，我要把你雷成碎片」「是我千辛万苦把你炼成精灵、炼成精华，下的苦功够我赢两回哲人石……你要在投射里爆飞出去？」），人物泼辣鲜活，极具舞台对白爆发力。

2. **第二幕玛蒙爵士的贪欲狂想（Scene I & II）**：
   玛蒙爵士对于财富与肉欲的宏大幻象（「把德文郡和康沃尔郡买下，点成地地道道的印度」「所有的床都要用气吹起来，不用填絮……用太阳之精和溶化的珍珠煮鲤鱼舌、睡鼠、驼蹄」），中文用词铺陈华丽，完美再现了琼森笔下伊壁鸠鲁式狂妄贪婪的滑稽癖性。

3. **第四幕多尔狂背宗教伪预言（Scene V）**：
   多尔假扮疯癫贵妇背诵休·布劳顿（Hugh Broughton）的经文末世年表（「佩尔狄卡斯与安提柯纳斯既诛，存者二人，塞琉古与托勒密……构成两腿与第四兽，即歌格为北、埃及为南」），古雅断烂，文气逼真，双语对照严丝合缝。
