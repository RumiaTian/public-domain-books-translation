# 术语表（anthony-trollope_short-fiction）

> 本项目为**短篇集**：41 篇相互独立，人物不跨篇。本表只收**跨篇复用**的专名与统一策略；各篇内部人物/地名由该篇译者在篇内自行统一，首次出现附原文「中文（English）」。

---

## 一、译法策略

| 类别 | 策略 |
|------|------|
| 人名 | 音译，从通行译名（如 Brown 布朗、Graham 格雷厄姆）；姓前不加「先生/夫人」，敬称 Mr./Mrs./Miss 单独译（布朗先生）；昵称用中文对应亲昵形式（Hetta 海蒂） |
| 敬称/头衔 | Rev./the Rev. →「牧师/ Reverend 」译「尊敬的」不通行，径译「××牧师」；Sir+名 →「××爵士」；Lady →「××夫人/女士」按语境；Duke/Marquis/Baronet → 公爵/侯爵/从男爵；Frau/Herr（德语）保留原词或译「××太太/先生」，按篇内语感统一 |
| 地名 | 用通行译名：London 伦敦、Paris 巴黎、Antwerp 安特卫普、Vienna 维也纳、Munich 慕尼黑、Venice 威尼斯、Jerusalem 耶路撒冷、Cairo 开罗、Dublin 都柏林、Albany 奥尔巴尼。郡名意译后加「郡」（County Mayo 梅奥郡、Somersetshire 萨默塞特郡）；虚构小镇（Plumplington、Beetham、Ballymoy 等）音译 |
| 货币 | pound → 英镑；shilling → 先令；sovereign（金币）→ 沙弗林金币（首次简注=1英镑）；guinea → 几尼；franc → 法郎；dollar（美国篇）→ 美元。数字照录 |
| 度量衡 | mile → 英里（可括注约合公里，全篇统一即可）；英制单位照录不换算 |
| 罗马数字/年份/尺寸 | 照搬不译（如 Christmas of 187‒ 保留「187‒年圣诞节」式破折号缺字） |
| 刊物名 | 斜体刊名（*Times*、*Panjandrum Magazine*）保留斜体，首现附中文译名《泰晤士报》《潘詹德鲁姆杂志》 |
| 外文残句 | 法/德/意语日常短语照录原文并括注中译（或径译）；圣经引文用和合本文体 |
