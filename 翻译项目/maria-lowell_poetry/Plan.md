## 文件分工

| 文件 | 作用 | 谁来改 |
|------|------|--------|
| `项目说明.md` | 项目基本信息、诗歌翻译专则 | 人工 |
| `术语表.md` | 翻译硬约束层 | agent / 人工 |
| `translation_queue.csv` | 任务队列（file,size_kb,status） | 翻译前 doing，完成 done |
| `Plan.md`（本文件） | 执行步骤 + 运行日志 | agent 追加日志 |
| `原文/*.md` | 源文（20 首诗，每首一文件） | 不改 |
| `译文/*.zh-CN.md` | 译文产出（块对照双语） | 翻译 agent 产出 |

## 执行步骤

按 `prompts/翻译计划模板.md`「执行步骤」9 步推进。**诗歌块格式与分行规则以项目说明.md「备注·诗歌翻译专则」为准**（每首一块、块内逐行对应、诗节间空行保留、尽量再现韵式），优先于通用规则。

## 篇目清单

20 首诗，每首独立成篇，详见 `translation_queue.csv`（01-the-maidens-harvest.md … 20-memories-of-waters.md，共 27.2 KB）。诗题中文译名见 `术语表.md`「诗题 / 篇名」。
