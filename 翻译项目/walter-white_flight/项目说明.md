- **源语言**：英语

- **内容简述**：沃尔特·怀特（Walter White, 1893–1955，NAACP 领袖、哈莱姆文艺复兴时期作家）的小说《逃亡》（*Flight*, 1926）。路易斯安那克里奥尔裔浅肤色有色人女子咪咪·达坎（Mimi Daquin）随父与继母自新奥尔良迁居亚特兰大，在黑人资产阶级令人窒息的循规蹈矩中觉醒种族与性别意识，历经一段形同陌路的婚姻，最终出走纽约、在黑人灵歌中找回本族身份（「自由！自由！自由！」）。本书以「冒充白人」（passing）为核心张力，与作者另一部《火中剑》同类，是种族与性别抗争主题小说。

## 备注

- **种族用语分级处理**（与《火中剑》项目同原则，作者怀特同为 NAACP 领袖，保留批判冲击力）：
  - **Negro** → 黑人（叙述与有色人角色用语，首现附原文加译注说明历史语境）
  - **coloured / colored** → 有色人（时期拼写，指美国黑人；「For Coloured」候车室等为吉姆·克劳隔离设施）
  - **nigger / niggers** → 黑鬼（白人种族主义贬语，**保留其贬义冲击力**，不软化，首现加译注）
- **「冒充白人」（passing）主题**：主人公咪咪浅肤色（红金发、奶油色面庞），可被当作白人——这是全书身份张力的核心，外貌描写须忠实译出以服务主题。
- **克里奥尔法语词**（petite / chérie / maman / Petit Jean 等）保留原文斜体并附译，存其路易斯安那文化底色。
- **黑人市井方言**（金太太、普卢默太太等：'Cose / ain't / mo' / ev'rybody）→ 中文乡土口吻，不用怪异拼写。
- 主人公 Mimi Daquin → 咪咪·达坎；其父 Jean Daquin → 让·达坎（罗伯逊先生昵称其「Gene」）。
- 1926 年出版，叙事起于 1905 年前后（日俄战争报童叫卖语为时间锚点），跨新奥尔良/亚特兰大/费城/纽约四地。
