# 术语表（H·P·洛夫克拉夫特短篇小说集）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。洛夫克拉夫特自造大量专有名词（克苏鲁神话体系），本表给出统一的、与中文克苏鲁神话爱好者社群通行译法一致的音译/意译方案，全书一律照此。

## 翻译策略说明

1. **文体基调**：洛夫克拉夫特行文刻意古奥、繁复、长句层叠（18—19 世纪书面英语＋世纪末哥特腔）。译文取**偏书面、略带文言色彩的现代汉语**，保留其沉重、迂缓、压抑的节奏；叙事部分宁可稍文雅，对话贴合角色。避免轻快的现代口语破坏氛围。
2. **自造专有名词**：宇宙神祇、虚构地名一律采用中文克苏鲁神话（Cthulhu Mythos）社群的**通行译名**，音译为主、意译造词为辅，全书统一。首次出现以「中文（Original）」括注原文，后文统一用中文。
3. **咒语 / 祷词 / 异语**：如 "Ph'nglui mglw'nafh Cthulhu R'lyeh wgah'nagl fhtagn" 一类不可解的祭祀诵词，**保留原文拉丁字母转写**不译，首次出现处简注其意（"在拉莱耶的宅邸中，长眠的克苏鲁候汝入梦"）。
4. **罗马数字**：各篇分节标记（I / II / III …）照搬不译。
5. **法语 / 拉丁语 / 希腊语**短句：保留原文，必要时加简注中译。
6. **度量衡 / 货币**：英里、英尺、英寸等保留并首次换算括注（如「三英里（约五公里）」），全书统一；英镑、先令等保留原名括注价值。
7. **New England 地名**：真实地名（Providence, Boston, Salem, the Merrimack 等）用通行中译；虚构地名见下表。
