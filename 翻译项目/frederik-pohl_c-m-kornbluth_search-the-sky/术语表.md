# 术语表（Search the Sky／搜寻天空）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **人名音译**，首次出现附原文「中文（English）」，全文统一。头衔 Mr./Mrs./Captain/Doc 译「先生/夫人/船长/医生」，Doc Jones 统一「琼斯医生」。
- **行星/城市名**音译（Azor 阿佐尔、Gemser 格姆瑟等），作者自造的殖民星地名按发音+斯拉夫风后缀处理（Novj Grad 诺夫格拉德）；地球真实地名（Australia、Chicago、Evanston、Brooklyn）用通行译名。
- **船名/空间站名**加「」并加「号」：the *Minerva* = 「密涅瓦」号；the *Sirius IV* = 「天狼星四号」；the *Thetis* = 「忒提斯」号。
- **缩写照搬不译**：F.T.L.（超光速）、G.C.A.（地面控制进场）、R.C.、S.O.P.；首次出现可加括注说明含义。
- **韦斯利系统**（Wesley board / Wesley Drive / Wesley Effect / Wesley combination）统一「韦斯利+功能词」：操舵板／驱动／效应，是本宇宙的超光速航行体系，以发明者 Wesley 命名。
- **度量、年份、坐标、罗马数字章节号**（I–XIV）照搬不译。
- **讽刺造词**保留构词法：Jonesology/Jonesfearing/Jonesism 统一「琼斯学／畏琼斯派／琼斯主义」式「琼斯+X」造词；Old Landowners / New Nobodies 译「旧地主家／新无名辈」保留阶层的戏谑对比。
- 全书题眼 **Decay**（第 1 章反复出现）统一译「衰败」，作为贯穿全书的主题词前后呼应。
