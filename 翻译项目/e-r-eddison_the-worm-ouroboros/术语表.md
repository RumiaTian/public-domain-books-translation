# 术语表（《衔尾蛇》）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

本书（E. R. Eddison, *The Worm Ouroboros*, 1922）是高奇幻文学奠基之作，行文刻意仿效詹姆士一世时代（Jacobean）的古雅英文：词汇古奥、句式绵长、多用倒装与虚拟语气、以 -th 词尾（hath/doth/saith）和古拼写为标志。翻译总原则见 `prompts/领域配置/小说文学.md`；本书特有约定如下：

- **文体基调——文白相间、典雅书面语**：叙事部分用略带文言色彩的雅致白话（庄重、凝练、有古意），对白部分依角色身份或王侯气度或武夫豪气，均保持典雅而克制的语体；忌现代口语、网络腔、翻译腔。古英文 -th 词尾、倒装句、祈使与虚拟语气所传递的庄严感，以中文的文言虚词（乃、遂、方、正、尚、惟、岂……）与四字格、整饬句式再现，但不通篇拟古以致生涩。
- **五大国名——意译＋「国」**（世界设定于水星，五族各以神怪之名立国，族名与字面义无关，故取意译以求雅驯可读，词根不可与本族字面雷同混淆）：
  - Witchland = 巫国（族人称 the Witches = 巫国人）
  - Demonland = 魔国（族人称 the Demons = 魔国人；**注意：魔国是本书主角一方，乃高贵英雄之族，非邪魔**）
  - Impland = 妖国（族人称 the Imps = 妖国人）
  - Goblinland = 哥布林国（Goblin 一词中文通行音译「哥布林」，以避与「妖国」相混）
  - Pixyland = 精灵国（族人称 the Pixies = 精灵国人）
- **人名、地名——按作者在献词（dedication）中亲注的读音音译**，全书统一；首次出现标「中文（English）」，其后统一用中文译名。音译依下述读音要点（献词原注）：Carcë 的 ë 读长音（如 Phryne 之 e，即 car-SEE）；Krothering 重音在 Kroth 音节、o 短；Corund 重音在第一音节 COR-und；Prezmyra 重音在第二音节 pre-ZMY-ra；Brandoch Daha 重音在第一、第四音节；Gorice 重音在末音节、与 thrice 押韵（go-RISE）；Corinius 与 Flaminius 押韵；Galing 与 sailing 押韵（GA-ling）；La Fireez 与 desire ease 押韵（la fi-REEZ）；ch 一律发喉音（如 loch）。
- **罗马数字照搬不译**：章节号（I, II, … XXXIII）、国王即位序数（Gorice XI = 戈里斯十一世）、年代纪元（ACC = *Anno Carces Conditae*，自喀尔刻建城之年，照搬或注「喀尔刻纪元」）。章节标题中的罗马数字与英文标题合并为「罗马数字 / 中文」格式，正文标题层级保留。
- **称号、头衔**：Lord = 大人／公（视语境，Lord Juss 作「朱斯大人」）；Duke = 公爵；King = 国王；Queen = 女王／王后（视语境）；the three brethren = 三兄弟（朱斯、戈尔德里、斯皮特法厄）；fosterling of the Gods = 众神之养女。
- **度量、货币、古物**：mile/league 之类酌情保留并意译（如 league = 里格）；古兵器甲胄（kirtle, doublet, habergeon, mace, glaive）用中文对应古称，全书一致。
- **神话生物**：hippogriff = 鹫马（鹰首马身有翼兽）；martlet = 无足燕（纹章中无足之燕，为引路灵禽）；manticore = 曼提柯尔（食人兽，音译）；the Worm = 大蛇／巨蟒（archaic 义「蛇、龙」，非「虫」）；the Worm Ouroboros = 衔尾蛇。
- **诗集/引诗**：书中所引古英诗、拉丁诗多为真实历史诗篇（邓巴、卡鲁、莎士比亚第十八首等），附录二已列出处；译文力求以相应古雅诗体再现，必要时注明原诗作者。
