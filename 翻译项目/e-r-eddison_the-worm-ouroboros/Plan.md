# 翻译计划（《衔尾蛇》）

## 本计划信息

- **项目名称**：《衔尾蛇》（E. R. Eddison, *The Worm Ouroboros*）
- **源文目录**：原文/
- **译文目录**：译文/
- **译文命名**：原名.zh-CN.md（放译文目录）
- **领域配置**：prompts/领域配置/小说文学.md
- **术语表**：术语表.md

## 文件分工

| 文件 | 作用 | 谁来改 |
|------|------|--------|
| `项目说明.md` | 项目基本信息、领域配置、篇目清单 | 人工 |
| `术语表.md` | 翻译硬约束层。每篇译完补充新词 | agent / 人工 |
| `translation_queue.csv` | 任务队列。每行一文件，`file, size_kb, status` 三列 | 翻译前改 doing，完成后改 done |
| `Plan.md`（本文件） | 执行步骤 + 运行日志 | agent 追加日志 |
| `原文/*.md` | 源文 | 不改 |
| `译文/*.zh-CN.md` | 译文产出（块对照双语） | 翻译 agent 产出 |

## 执行步骤

按 `prompts/翻译计划模板.md`「执行步骤」9 步推进（读配置 → 取 todo → doing → 读源文 → 翻译 → 自检 → check_bilingual.py → 双写 done → 日志）。本书为长篇，走委派模式，每篇由子代理在独立上下文执行 9 步；首篇（prologue.md）译成后兼作黄金样本，统一全书文白相间的古雅文体与专名音译。

## 篇目清单

正文 34 篇：引子（The Induction）＋ 第三十三章。各篇大小见 `translation_queue.csv`。源文最大者 chapter-12（57.7KB）、chapter-7（56.7KB）、chapter-31（47.2KB）属长文，按通用翻译引擎第七节分段处理。
