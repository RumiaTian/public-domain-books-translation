# 项目说明

## 基本信息

- **项目名称**：《过渡》（多萝西·米勒·理查森）/ Interim (Dorothy M. Richardson)
- **源语言**：英语
- **目标语言**：中文
- **内容简述**：本书是英国作家多萝西·米勒·理查森《朝圣》（Pilgrimage）十三卷序列的第五部（Standard Ebooks 元数据 group-position 5；1919 年初版），最早的意识流小说代表作之一。延续主人公米丽亚姆·亨德森的内心历程：她在伦敦温波尔街一家牙医诊所任秘书，栖身于坦斯利街贝利太太正"改作接待外国人的英国家庭"的寄宿舍。圣诞夜她北访布鲁姆家（菲尔普斯太太与外甥女格蕾丝、弗洛莉）寄居数日；元旦独守冷阁定下"新年宏愿"，自此寄宿舍里涌入各色外国人——世界主义者门迪萨尔、寒素的鲍登、"金属般冷硬"的挪威青年赫尔辛、施特雷林斯基、冈纳、罗德金等——米丽亚姆冷眼打量又暗自共振，在客厅孤弹肖邦与贝多芬、读《牙科宇宙》的气质学说自困、与门迪萨尔法语交锋，于"居间／过渡"（interim）的人生里捕捉自我的真实。全书以贴紧米丽亚姆意识的自由间接引语，铺陈她对寄宿舍众生与伦敦街景的观察、对孤独与归属的反复思量。叙事绵延流动、感官印象密集、内心独白与思绪跳跃贯穿始终。

## 备注

- 全书 11 章（罗马数字 I–XI），单一连续叙事弧（米丽亚姆圣诞寄居布鲁姆家、新年独处定愿、寄宿舍群像与各色外国客、客厅独奏与自我省察）。章数 ≤15 且不可分割的整体 → 中篇 → 连续模式。全书约 33.2 万字节 / 5.6 万英文词，篇幅在短篇与长篇之间，属"短长篇/中篇"体量；主 agent 连续翻译时单批受上下文限制，可分批推进。
- 与姊妹项目《尖顶屋》（卷一）、《僵局》（卷六）同属《朝圣》序列，共享主人公米丽亚姆·亨德森及意识流语体。人物（亨德森姐妹、贝利太太寄宿舍众客、温波尔街牙医合伙人）、地名（坦斯利街、温波尔街）、翻译策略须与两者术语表严格一致。
- **核心风格约束**：意识流。译文必须保留米丽亚姆内向、反思、跳跃的意识语体——大量自由间接引语、省略号（……）、破折号、片段式短语构成思绪的绵延与断流，不可"理顺"为平铺直叙的外视角叙述。详见术语表"翻译策略"。
- **外来寄宿客的"异乡人"语调**是本书特有难点：贝利太太寄宿舍聚居各色外国人，原文偶以谐音拼写或误读呈现其非母语英语（如门迪萨尔的姓被读作 Mendizabal / Mendizabble / Mendizzable / Mendy）。中文不取谐音字还原，而以略带外来腔、热情、书卷气或拘谨的句式传递其异乡人身份，全文一致；详见术语表"翻译策略"。切忌用方言、怪字制造廉价"口音感"。
- 文中穿插法语对白（门迪萨尔、施特雷林斯基等）及密集音乐意象（肖邦夜曲、贝多芬奏鸣曲、莫什科夫斯基《小夜曲》）与体液气质学说（lymphatico-nervous 等）。法语保留原文并紧跟中译；曲名/人名用通行译名，首次附原文。
- 章节标题为罗马数字 I–XI，照搬不译。
- 本书扉页有献词「To F. de B.」（献给 F. de B.），原文提取时单列；为与姊妹项目结构一致（仅章节文件），献词未单列为翻译条目，可于卷首附「献给 F. de B.」一行。
