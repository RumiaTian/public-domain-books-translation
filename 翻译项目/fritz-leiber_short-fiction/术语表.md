# 术语表（弗里茨·莱伯短篇科幻小说集）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。本书 25 篇互为独立短篇，但共享若干作者惯用元素（战后末世、机器人、纽约背景），统一处理。

## 翻译策略

- **作者与文风**：弗里茨·莱伯（Fritz Leiber, 1910–1992），美国科幻/奇幻/恐怖大师，文风都市化、机智反讽、善用口语与流行文化典故。译文宜保留其轻快的第一人称叙述口吻与冷幽默，避免过度书面化。
- **篇目独立**：各篇人物、设定互不衔接，人名/地名在篇内保持一致即可；跨篇共享元素按本表统一。
- **人名地名**：音译为主，首次出现附原文「中文（English）」；虚构小地名（如 Nowhere、It）按篇内语境意译并首次附原文。
- **科幻术语**：用通行译法并全书统一：space guard=太空巡逻队 / robot=机器人 / atom bomb=原子弹 / radiation=辐射 / Geiger counter=盖革计数器。
- **末世/战后设定**（多篇共享）：Last War / World War III 统一译「上次大战 / 第三次世界大战」，post-war 世界基调统一为「战后」；the Deathlands（长刀之夜篇）译「死地」，为该篇专有。
- **机器人专名**：Robie（罗比）、Black Sorter（黑分拣机）等篇内专名音译/意译后篇内统一，首次附原文。
- **度量衡与货币**：英里、磅、美元等保留原文数字不换算，全书统一。
- **文学典故**：涉及莎士比亚（No Great Magic 篇）台词参照朱生豪/通行中译风格，人物 Queen Elizabeth 译「伊丽莎白女王」；Lady Macbeth 译「麦克白夫人」。
- **标题格式**：双语文件中标题一律「英文 / 中文」合并，篇名意译为主、保留原题韵味。
