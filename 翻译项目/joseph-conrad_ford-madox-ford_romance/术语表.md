# 术语表（《罗曼史》）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略说明

- 本书为约瑟夫·康拉德（Joseph Conrad）与福特·马多克斯·福特（Ford Madox Ford）1903 年合著的长篇小说。约 1820 年代（乔治四世时期）背景，前半在肯特郡与牙买加，后半在古巴北岸海盗镇里奥梅迪奥与伦敦老贝利。译文保持浪漫传奇的叙事声口：第一人称回望、怀旧而带反讽。
- **书名**：Romance 译《罗曼史》；全书主题词 romance（对照现实之「浪漫传奇／浪漫际遇」）按语境译，点题处（卷五结尾 "That, too, is Romance!"）保留大写并统一作「罗曼史」。
- **人名**：西班牙人名按通行音译，首次出现附原文「中文（Spanish）」；英语人名按英语音译。
- **西班牙语称谓**：Don/Doña 译「堂／堂娜」+名（如 Don Balthasar → 堂巴尔塔萨）；Señor/Señorita 视语境译「先生／小姐」或与名字连用；hermano、citizen 类呼语意译。
- **西班牙语词句与咒语**（*vaya usted con Dios*、*Basta*、*Pero*、*Juanino* 等）：作品特色，照录斜体原文并附首次中文释义，保留跨语种叙事质感；高频短词（Basta、Pero）可直接译「够了」「可是」，首次出现时注明原词。
- **海盗绰号**：El Demonio / Diableto → 「恶魔」（首现附原文）；Nikola el Escoces → 「苏格兰人尼古拉」（Nikola el Escoces，首现附原文）；el Inglez → 「英国人」（西语绰号，照录附释义）。
- **海事与西印度用语**：picaroons → 海寇；letter of marque → 私掠特许状／捕获许可证；capataz → 头目；pen（牙买加语境）→ 庄园（牧场式庄园）；schooner/tender 等按航海惯例。
- **罗马数字**：部号（Part I–V）与章号（I–XI）照搬不译。
- **缩写**：Mr./Mrs./Dr. 译「先生／夫人／医生」；地名缩写（S.S.E. 等）照搬。
- **两个 Thames**：斜体 *Thames* 为船名「泰晤士号」，非斜体 the Thames 为泰晤士河，切勿混淆。
