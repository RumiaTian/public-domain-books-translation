# 术语表（马拉科特深渊）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **人名音译**，首次出现附原文「中文（English）」，全文统一。科学家/学者头衔 Dr. / Mr. / Professor / Sir / Captain / Mrs. 译为「博士/先生/教授/爵士/船长/夫人」，全书一致。
- **船名**加书名号并加「号」：the *Stratford* = 「斯特拉特福德」号；英文斜体保留或并入中文均可，但译文中书名号「」统一使用。
- **地名**用通行译名（大加那利岛、法罗群岛、阿尔伯特码头等）；海岭/海沟/大陆坡等海洋地理术语用学界通用译法。
- **作者新造词**（levigen、vitrine bell 等）采音译或音译+意译并首次附原文；科技仪器术语采意译。
- **罗马数字章节编号**（I–VII）、度量单位（fathom=英寻、tons=吨）、年份照搬不译。
- 本书含「通灵/降神/白魔法对抗黑魔法」主题，相关术语（materialist=唯物论者、the spirit=灵体、plane of spirit=灵界/精神层面）需统一处理，保持柯南·道尔晚期唯灵论语境。
