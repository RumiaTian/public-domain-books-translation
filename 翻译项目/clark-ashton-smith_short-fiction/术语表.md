# 术语表（克拉克·阿什顿·史密斯短篇科幻奇幻集）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **史密斯的文体是巴洛克式、颓靡华丽的怪奇散文**：大量古词、生僻词、堆砌的形容词与名词并列（如 "glaucous"、"fulvous"、"eld"、"perdurable"）。译文须保留这种**繁复、古雅、阴郁**的文学质感，多用四字格与书面文言色彩词汇，避免译成平白现代汉语。
- **自创架空世界（invented worlds）**是史密斯的标志。本集涉及的架空地名（Averoigne / Hyperborea / Poseidonis / Yondo / Sadastor）一律采用通行译名，首次出现附原文。
- **新造/异域专名音译策略**：按发音音译，选字倾向古雅、略带异域神秘感（如 Sadastor 译「萨达斯托」而非「萨达斯特」）。法语专名（Averoigne 系列中的 Faussesflammes、Venteillon 等）按法语发音音译，必要时附原义简注。
- **印度/马来语借词**（krise、prahus、mahout、sahib 等）：保留通行译法，首次出现附原文。
- 希腊罗马神话专名（Tartarus、Python、Lethe、Saturn 等）用通行译名。
- 罗马数字编号、拉丁文引语照搬不译，必要时加注。
- 各篇人物、地名独立，但跨篇出现的架空世界（如 Averoigne）译法须全书一致。
