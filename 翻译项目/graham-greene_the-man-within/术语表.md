# 术语表（The Man Within / 内心的人）

## 走私术语与器物

| 译名 | 原文 | 说明 |
|------|------|------|
| 「好机遇号」 | the Good Chance | 走私用的双桅小帆船船名，斜体保留 |
| 走私贩子 | runners | 口语中指搬运私货的走私者，视语境亦可译「跑货的」 |
| 缉私税吏 | gaugers | 民间对税务/缉私人员的称呼 |
| 缉私官员 | revenue officers | 官方称呼；the revenue（海关税务机构）译「缉私局/税务当局」 |
| 私货 | contraband | 违禁品，语境中多指走私酒类 |
| 酒桶 | casks | 走私货物容器 |
| 双桅小帆船 | lugger | 走私船型 |
| 走私一批货 | run a cargo | 走私行动的黑话 |
| 巡回法庭 | the Assizes / Assize Court | 定期巡回审判法庭 |
| 走私团伙 | the gang / smugglers | smugglers 统一译「走私者/走私贩」，视语境 |
