# 术语表（埃德加·爱伦·坡短篇小说集）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **作者名**：Edgar Allan Poe 统一译「埃德加·爱伦·坡」（行文中可简称「爱伦·坡」）。
- **人名**：各篇人物基本独立。英语人名按通行译名音译，首次出现附原文「中文（English）」；已有固定译名者用固定译名（如 Dupin=杜宾）。法语、德语、匈牙利语人名按相应语言习惯音译。
- **地名**：欧美通用地名用通行译法（Paris=巴黎、Hungary=匈牙利等）；巴黎街道名（Rue …）保留「……街」意译并首次括注原文。
- **侦探三部曲**（the-murders-in-the-rue-morgue / the-mystery-of-marie-roget / the-purloined-letter）共享人物：C. Auguste Dupin 与无名叙述者「我」、巴黎警察局长 G 先生，译法须三篇一致。
- **拉丁文题词 / 法文引语**：坡好用拉丁文题词（如 Seneca、Luther 句）与法文夹叙。处理原则——**先给出中文译文，再以括号保留原文**（题词格式：「中文译文（Latin/French 原文）」）。简短人名署注（如 Martin Luther）照译，不译人名原文。诗歌体题词分行照排。
- **罗马数字编号**（章次、卷次、年号）照搬不译。
- **坡式造词 / 复合形容词**（如 out-Heroded Herod、 Salvatorish）：尽量在中文里再造对应修辞效果，必要时意译并简注。
- **哥特意象与氛围词**（preternatural、ghastly、sepulchre、cadaverous 等）：全篇基调阴郁华丽，译文用稍文雅、有质感的中文，避免口语化冲淡哥特气氛。
- **拟古 / 圣经 / 神话典故**（Caligula、Saracen、Vathek、Scheherazade、Metempsychosis 等）：意译为主，关键专名首次括注原文。
- **度量衡 / 货币**：保留并附约略换算（如「五十英里」），全书统一。
- **报纸 / 刊物名**（Tribune、Home Journal 等）：译中文并首次括注原文。
