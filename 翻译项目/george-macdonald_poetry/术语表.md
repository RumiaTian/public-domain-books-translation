# 术语表：George MacDonald Poetry（乔治·麦克唐纳诗集）

> 全书 229 首诗作（1857–1893）+ 尾注。以下词条为通读样篇（开卷组诗、中段叙事诗与灵修日记、末卷谐趣诗）所建初版；**每篇译毕由译者在「补充词条」区追加新词**，保持全书统一。

## 翻译策略

- **诗题**：意译为主，兼顾诗境与简洁；无题诗（以首行代题者）以首行关键意象定题。同一诗题加中文译题后缀区分（如同题组诗用「之一/之二」）。
- **人名、地名**：音译，首次出现附原文「中文（English）」；后续用译名。圣经人物、神话人物、历史名人一律用通行译名。
- **基督教语域**：God／Lord／Christ／Holy Ghost 等按下方「宗教用语表」统一译法，全书不得混用。
- **古雅用词**：19 世纪诗歌用语（thou / thee / thy / doth / hath / goeth / o'er / ye / 'tis / 'twixt / whence 等）以庄重、略带文言色彩的中文再现，但求可读。
- **照搬不译**：罗马数字编号（I / II / III）、月份周次编号、年代、篇末署名缩写（G. M. D. Jr. 等）、戏剧体 persona 名（1st Echo 等）、拟声词（Bang! Bing! Bome!）、外文币制/度量单位。年代可作中文数字（1857 → 一八五七）。
- **拟人化抽象名词**（Death / Nature / Truth / Love 等）大写起首表拟人时，译作「死神 / 大自然（母亲）/ 真理 / 爱」等并保持全书一致；非拟人处照普通名词译。
- **诗歌分行、韵式与版式规则**见 `项目说明.md`「备注·诗歌翻译专则」，优先于小说文学领域配置。
