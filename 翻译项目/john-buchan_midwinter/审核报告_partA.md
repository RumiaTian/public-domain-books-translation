## 四、术语与典故专项抽查核验

前半卷涉及大量 1745 年苏格兰雅各布党叛乱历史、英格兰与苏格兰地理、古典神话典故及十八世纪文人掌故，抽查结果如下：

1. **核心主角与暗号体系**：
   - `Alastair Maclean` -> 阿拉斯泰尔·麦克莱恩（统一规范，音形兼美）
   - `Amos Midwinter` -> 埃莫斯·仲冬（奥特沼泽提琴手哲人，与术语表纠偏完全一致）
   - `the Spoonbills` / `the Bog-blitters` / `the Left-Handed` (`ciotach`) / `the Naked Men` -> 篦鹭会 / 沼怪帮 / 左手党（盖尔语 ciotach 附注精当） / 赤身人（神秘会社系统完整贯通）
   - 暗号代号：`Alcinous`（阿尔基努斯）、`Menelaus`（墨涅拉俄斯）、`Achilles`（阿喀琉斯）、`Briseis`（布里塞伊斯）、`Tekel`（提客勒）、`Mene`（弥尼）全部契合原著《奥德赛》与《圣经·但以理书》隐喻。
2. **重要历史与文学人物**：
   - `Samuel Johnson` -> 塞缪尔·约翰逊（年轻时代的约翰逊博士，瘰疬疤痕、手背抽搐、庞大笨拙而傲骨铮铮的形象跃然纸上，尤维纳利斯讽刺诗、史密斯菲尔德拳术典故均极为贴切传神）
   - `Kitty, Duchess of Queensberry` -> 昆斯伯里公爵夫人基蒂（凡尔赛风流、牧羊女时装、俏皮机警刻画入微）
   - `Lord Cornbury` -> 科恩伯里勋爵（温文高贵而深思踌躇之态传神）
   - `Charles P.` / `the Prince` -> 查理·P. / 王子殿下
   - `General Oglethorpe` -> 奥格尔索普将军（募兵佐治亚背景准确）
3. **地理与风物考据**：
   - 英格兰中部与西部：`Wychwood`（威奇伍德森林）、`Evenlode`（埃文洛德河）、`Cherwell`（切尔韦尔河谷）、`Otmoor`（奥特沼泽）、`Charlbury`（查尔伯里）、`Staffordshire`（斯塔福德郡）、`Shropshire`（什罗普郡）、`Flambury`（弗兰伯里）、`Cheshire`（柴郡）、`Derbyshire`（德比郡）、`the Peak`（皮克山）等全部准确规范。
   - 高地与群岛：`Hebrides`（赫布里底）、`Morvern`（莫尔文）、`Loch Sunart`（苏纳特湖）、`Lochaber`（洛哈伯）、`Sgurr Dubh`（斯古尔·杜）、`Sgurr Mór`（斯古尔·莫尔）译名典雅统一。
   - 器物与风俗：`double Gloucester`（双重格洛斯特干酪）、`spiced October`（加香十月酿）、`haggis`（哈吉斯）、`but-and-ben`（两间小舍）、`cambric`（细麻纱/细白布）、`negus`（尼格斯热酒）等极具时代与地方风貌。
