# 项目说明

## 基本信息

- **项目名称**：《尖顶屋》（多萝西·米勒·理查森）/ Pointed Roofs (Dorothy M. Richardson)
- **源语言**：英语
- **目标语言**：中文
- **内容简述**：本书是英国作家多萝西·米勒·理查森《朝圣》（Pilgrimage）十三卷序列的第一部，也是公认的最早的意识流小说之一。故事设定在1890年代初，17岁的米丽亚姆·亨德森因家道中落，被送往德国汉诺威一所女子寄宿学校教授英语。全书以贴紧米丽亚姆意识的自由间接引语，记述她在学校与师生相处的日常、出游郊野的见闻、对异乡生活的感受，以及她对宗教、文学、女性处境与自身前途的反复思量。叙事绵延流动、感官印象密集、内心独白与思绪跳跃贯穿始终。

## 备注

- 全书 10 章，单一连续叙事弧（米丽亚姆从伦敦赴德、在瓦尔德街学校度过一学期、期末返乡）。章数 ≤15 且不可分割的整体 → 中篇 → 连续模式。全书约 33.5 万字节 / 5.7 万英文词，篇幅在短篇与长篇之间，属"短长篇/中篇"体量；主 agent 连续翻译时单批受上下文限制，可分批推进。
- **核心风格约束**：意识流。译文必须保留米丽亚姆内向、反思、跳跃的意识语体——大量自由间接引语、省略号（……）、破折号、片段式短语构成思绪的绵延与断流，不可"理顺"为平铺直叙的外视角叙述。详见术语表"翻译策略"。
- 文中夹杂大量德语（校名、称呼、对话、歌词、祷词、内心独白）与少量法语。德/法语处理策略见术语表——作为场景与人物标识的短词保留原文并首次括注，歌词/祷词保留原文并紧跟中译。
- 章节标题为罗马数字 I–X，照搬不译。
