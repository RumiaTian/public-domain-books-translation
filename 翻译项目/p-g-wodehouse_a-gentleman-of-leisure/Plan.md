## 文件分工

| 文件 | 作用 | 谁来改 |
|------|------|--------|
| `项目说明.md` | 项目基本信息、领域配置、篇目清单 | 人工 |
| `术语表.md` | 翻译硬约束层。每篇译完补充新词 | agent / 人工 |
| `translation_queue.csv` | 任务队列。每行一文件，`file, size_kb, status` 三列 | 翻译前改 doing，完成后改 done |
| `Plan.md`（本文件） | 执行步骤 + 运行日志 | agent 追加日志 |
| `原文/*.md` | 源文 | 不改 |
| `译文/*.zh-CN.md` | 译文产出（块对照双语） | 翻译 agent 产出 |

## translation_queue.csv 格式

```
file,size_kb,status
00-dedication.md,0.1,todo
01-jimmy-makes-a-bet.md,15.5,todo
...
```

状态取值：`todo` / `doing` / `done`。

## 执行步骤（agent 按此推进，两种模式共用）

> 本书内容形态为「长篇」，执行模式为**委派**：主 agent 只当调度员，把每篇的 9 步下沉到一次性子代理执行（简报见 `WORKFLOW.md`「子代理简报」）。执行步骤全文见 `prompts/翻译计划模板.md`。

1. 读配置：本 Plan.md → 项目说明.md → 术语表.md → prompts/通用翻译引擎.md → prompts/领域配置/小说文学.md → 译文/ 下任意已完成 .zh-CN.md（黄金样本）
2. 取任务：读 translation_queue.csv 取第一个 todo；译文已存在则直接改 done
3. 读源文（原文/对应文件名）
4. 翻译：产出到 译文/对应文件名去.md加.zh-CN.md（块对照、标题合并「英文 / 中文」、不漏译不截断）
5. 自检（完整性、块对称、标题格式、术语一致）
6. `python scripts/check_bilingual.py 译文/对应篇名.zh-CN.md`
7. 回填状态（双写：项目 CSV + 根表）
8. 在本文件「运行日志」追加一行
9. 循环取下一篇 todo
