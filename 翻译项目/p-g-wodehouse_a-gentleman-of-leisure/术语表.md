# 术语表（P. G. 伍德豪斯《有闲绅士》）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **核心设定**：本书为 P. G. 伍德豪斯（P. G. Wodehouse）1910 年长篇小说（A Gentleman of Leisure，又译《有闲阶级绅士》）。纽约「闲逛者」俱乐部里，看完一出胜过《拉夫尔斯》的窃贼戏的富家青年吉米·皮特与人打赌：自己也能当一夜窃贼。他翻进纽约警察局长麦克伊彻恩（本名约翰·福雷斯特，原英国绅士，靠警界「油水」发财）的宅邸，偶遇其女莫莉，一见倾心。随后吉米应新交的德利弗小勋爵之邀赴英做客德里弗城堡；梁上君子斯派克·马林斯不请自来充作跟班，麦克伊彻恩带着莫莉与私家侦探盖勒也接踵而至——莫莉竟被安排与心上另有其人的小勋爵斯宾尼订婚。城堡主人托马斯·布伦特爵士疑心成癖、暗中布防。吉米一面行侠仗义救美人，一面将错就错把「窃贼」戏演到底，闹出连环笑剧；结局有情人成双登船返美。基调为典型伍德豪斯式闹剧：文笔轻盈机智、夸张滑稽、误会连环，译文须保持明快诙谐、略带漫画化的喜剧腔调。
- **人名**：音译为主，首次出现附原文「中文（English）」。贯穿全书的主要人物译法全书统一，与库内其他沃德豪斯项目（如《交给皮史密斯吧》）的译名习惯保持一致。
- **人物声口**（全书统一）：吉米·皮特——从容爽利、爱打趣的美式绅士腔；斯派克——纽约鲍里街（Bowery）窃贼黑话腔（Gee! / Say! / de / dat / dem / boss 等），译作相应的中文市井俚语（「哎呀！」「喂！」「老大」），与英式角色形成鲜明反差；斯宾尼（德利弗勋爵）——吞吞吐吐、被长辈揉搓的小少爷腔；托马斯爵士——粉团脸、疑神疑鬼的暴发户腔；麦克伊彻恩——大块头、外强中干的威严腔；莫莉——爽直娇俏。叙述者的插科打诨保留其打趣笔调。
- **称谓/头衔**：Sir Thomas 译「托马斯·布伦特爵士」（Sir Thomas Blunt）；Lord Dreever 译「德利弗勋爵」（指老勋爵时同）；Lady Julia 译「朱莉娅夫人」；the Hon. Louis Hargate 译「路易斯·哈盖特（Hon.，荣誉头衔）」。Mrs./Mr./Miss 译「太太/先生/小姐」；Captain（of Police）译「（警察）局长」。
- **机构/场所**：英国地名按通行译法（London 伦敦、New York 纽约）；虚构地名 Dreever 系统一律译「德里弗」；详见「地点与场所」表。
- **货币/度量**：dollar（美元）为美国场景主货币，pound（英镑）为英国场景，照常译出；mile（英里）、yard（码）保留。
- **罗马数字**：章号（I–XXX）照搬保留，不译；戏名、报名、船名等首次出现附原文。
- **章题**：各章标题为「罗马数字 + 文字名」（如 `## I Jimmy Makes a Bet`），译文标题行作「## I Jimmy Makes a Bet / 吉米打赌」，罗马数字章号照原样保留。章内场景分隔线 `---` 照搬保留。
- **关键情节代号**：①「伦敦来的窃贼（a crook from London）」——吉米被麦克伊彻恩堵住时顺水推舟的假身份（还吹嘘撬过伦巴第街的「亚细亚银行」），贯穿全书，前后口径一致。②「打赌」——第 1 章吉米与俱乐部众人所订之赌（一夜窃贼），是全部故事的引线。③订婚骗局——莫莉被迫与斯宾尼订婚（第 16 章「婚事已定」），斯宾尼另有所爱；第 18 章「洛钦瓦尔之法」典出司各特长诗《马米恩》中洛钦瓦尔掳走新娘的典故，指吉米式的「劫走心上人」。④私家侦探——盖勒明里受麦克伊彻恩指使监视吉米，自称霍尔博恩 Wragge 侦探社雇员，向托马斯爵士递报告；斯派克与他「同行冤家」的明争暗斗是后半部笑料主线。

## 主要人物（贯穿全书）

| 原文 | 译法 | 备注 |
|------|------|------|
| Jimmy Pitt / Jimmy | 吉米·皮特（吉米） | 主角，美国富家青年；其母旧日爱慕者赴澳发财后遗赠巨款；「闲逛者」俱乐部成员，因打赌当了一夜窃贼 |
| Molly McEachern | 莫莉·麦克伊彻恩 | 女主角，红发姑娘，麦克伊彻恩独女；爱骑马（坐骑「丹迪」）；被安排与斯宾尼订婚 |
| John McEachern | 约翰·麦克伊彻恩 | 纽约警察局长（Captain of Police）；本名约翰·福雷斯特（John Forrest），英国破落绅士出身，改名换姓赴美，靠警界「油水」（graft）发财；对女儿言听计从 |
| Spike Mullins | 斯派克·马林斯 | 纽约小窃贼，鲍里街黑话腔；当过侍者、珠宝店伙计（懂珠宝），与拳手「基德·布雷迪」撑过三回合；先与吉米在麦克伊彻恩宅相遇，后追到德里弗城堡充作跟班 |
| Sir Thomas Blunt | 托马斯·布伦特爵士 | 暴发骑士，精于生意、疑心成癖的矮胖粉团脸；娶斯宾尼姑母朱莉娅后实际掌控德里弗城堡；在堡中布下私家侦探 |
| Lady Julia Blunt | 朱莉娅·布伦特夫人 | 娘家姓库姆-克龙比（Coombe-Crombie），斯宾尼的姑母；当年德利弗家财困时与托马斯爵士「做成一笔满意的交易」 |
| Lord Dreever / Spennie | 德利弗勋爵 / 斯宾尼 | 全名希尔德布兰德·斯宾塞·波因斯·德·伯格·约翰·汉纳赛德·库姆-克龙比，第十二代德利弗伯爵；债台高筑的少年，被叔父强按着与莫莉订婚，另有所爱 |
| The Hon. Louis Hargate | 路易斯·哈盖特（荣誉头衔） | 斯宾尼在俱乐部结识的朋友，赌客；与吉米打皮克牌（第 20 章） |
| Mr. Samuel Galer | 塞缪尔·盖勒 | 自称纽约来客，由麦克伊彻恩在村中「偶遇」引入城堡；实为私家眼线，受麦克伊彻恩指使监视吉米，自称霍尔博恩 Wragge 侦探社所雇、向托马斯爵士递报告；与斯派克互为「同行冤家」 |
| Arthur Mifflin | 亚瑟·米夫林 | 英裔演员，吉米的老友，第 1 章在「闲逛者」俱乐部讲述吉米发家史 |
| Charteris | 查特里斯 | 剑桥「脚灯社」（Footlights）出身的戏剧迷，张罗城堡业余演剧 |
| Saunders | 桑德斯 | 德里弗城堡管家，托马斯爵士唯一信任的仆人 |

## 术语与文化

| 原文 | 译法 | 备注 |
|------|------|------|
| Raffles | 拉夫尔斯 | E. W. 霍南笔下绅士怪盗，「胜过《拉夫尔斯》的窃贼戏」即开场所观之剧的评语 |
| a crook from London | 「伦敦来的窃贼」 | 吉米的假身份，全书统一口径 |
| graft | 油水／灰色收入 | 麦克伊彻恩警界生财之道 |
| Wragge’s (private inquiry agency) | Wragge 私家侦探社 | 盖勒自称的东家，「老字号，专办离婚」 |
| Pyramus and Thisbe | 皮拉摩斯与提斯柏 | 莎剧《仲夏夜之梦》中的苦命情侣，第 2 章章题典故 |
| the Lochinvar method | 洛钦瓦尔之法 | 典出司各特《马米恩》——掳走新娘夺爱私奔；第 18 章章题 |
| piquet | 皮克牌 | 两人纸牌戏，第 20 章主戏 |
| pills | 台球 | 俚语（台球为「药丸」），照语境译「台球」并保留趣味 |
| oxyacetylene blow-pipe | 氧乙炔吹管 | 吉米向斯派克炫技时提及的破保险箱工具 |
| private theatricals | 业余演剧 | 查特里斯在城堡张罗的戏中戏 |
| footlights / the Footlights | 「脚灯」（剑桥脚灯社） | 剑桥学生戏剧团体 |
| boss / Gee! / Say! / dat / de / dem | 老大／哎呀！／喂！／这（那）／的／这些 | 斯派克的鲍里街黑话，统一用市井俚语腔译出 |
| Dandy | 「丹迪」 | 莫莉的坐骑马 |
