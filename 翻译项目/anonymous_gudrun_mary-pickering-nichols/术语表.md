# 术语表（Gudrun / 古德伦）

> 依据：原书自带 Names of Persons / Names of Places 两表 + 前言 + 首、中、尾章通读。
> 译法策略：德语史诗人名按德语读音音译，首次出现附原文「中文（English）」；真实国名用通行译名；虚构地名音译并在必要时括注含义。罗马数字（Tale I~XXXII）照搬不译。两位「Hilda」同名同译，靠上下文区分。

## 补充策略

- 诗行中人名呼格（如 "said Hagen" / "spake the knight"）保持简洁，以合诗行节奏。
- 货币、度量（mark、shield 等骑士文学惯用语）按语境意译（马克、盾牌），不加注释。
- 新出现的人名/地名按上表音译规则自行统一，首现附原文。
