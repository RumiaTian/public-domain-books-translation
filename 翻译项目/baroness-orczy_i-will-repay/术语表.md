# 术语表（baroness-orczy_i-will-repay）

> 翻译硬约束层。通读全书（序曲、首末章及全文专名频率扫描）后建立。每篇译后如遇新词，补充至此并保持全文统一。

## 翻译策略

- **人名**：法语人名音译，首次出现附原文「中文（French）」；姓氏带小品词（de/d'）的贵族姓连写（如 de Marny → 德·马尔尼）。英籍人物按英语译名惯例（Sir Percy → 珀西爵士）。
- **称谓**：Citizen/Citoyen/Citoyenne → 公民/女公民（大革命年月场景，即便对女性用 citizen 也译「公民」）；Monsieur/M. → 先生、Madame/Mme. → 夫人、Mademoiselle/Mlle. → 小姐、monsieur（小写泛称）→ 先生；M. le Marquis → 侯爵先生；Mon Colonel → 上校先生（我的上校）。
- **地名/机构**：巴黎地名从通行译名；革命机构从史学界通行译法（救国委员会、国民公会等）。
- **法语词句**：正文中零星法语（voyons l'aristo!、ma foi、pardi、sacré nom de nom!、n'est-ce pas 等）保留原文，按通用引擎规则紧随附译。
- **罗马数字、共和历月份（Fructidor 果月）、船名、书报名**：罗马数字照搬不译；共和历月名用定译「果月」；船名/报名首现附原文。
- **新造词/绰号**：意译为主（红花侠、独眼马客栈）。
