## 四、B 级问题（应修）—— 共 6 类

1. **专项① 词级英文对照块损坏 3 处**（EN 镜像与 `原文/*.md` 不一致，非字形归一）

   - ch9 行 115：源文 `for thou hast fallen by thine **iniquity**` → 英文块作 `thine **inequity**`（换词，KJV 引文被改）；`grep -o "thine inequity" 译文/chapter-9.zh-CN.md` 可复现。

2. **术语表违规 + 同名异译：`conversion/converted` 未按定名「归主」——共 7 处，跨 3 章**
   - 术语表：「conversion（sudden / instantaneous / gradual）→ 归主（顷刻 / 霎时 / 渐进）」。
   - 违规处（可 grep）：ch2 行 30「这些税吏和娼妓是当**悔改**；可我是正直的人，我不需要**悔改**」（源 `need to be converted` / `do not need to be converted`，2 处）；ch2 行 60「我们**用不着悔改**」（源 `we do not need to be converted`）；ch2 行 98「只要我愿意，就能**悔改**」（源 `I can be converted`）；ch2 行 142「我们不信瞬间的**悔改**」（源 `sudden conversions`）；ch3 行 56「需要**悔改归正**」（源 `needed to be converted`）；ch4 行 24「有些人的**归正**是那样渐进」（源 `are converted so gradually`）。
   - 合规对照：同书他处均作「归主」（ch2 行 31「使全家所有人都归主得救」、ch3 行 26「叫他归主」、ch4「顷刻归主／霎时之间发生的归主／渐进归主／初归主／归了主」、ch6「归主」×5、ch7 行 14「未曾归主」、ch9「从未归过主」×2），全书另有 29 处「归主」。
3. **人称敬称误用：`祂们` 指人 2 处**（ch5 行 65，同段内两见）
   - 源文 `The Jews put Christ to death because **they** said…` / `**They** said they did not want to hear more`，译作「犹太人把基督处死，因为**祂们**说祂并不是祂自己所宣告的那位」「**祂们**说不要再听了」。
   - 定性：`祂`/`祂们` 全书专用于神格（932 次），此处误施于人，属用词致义误。（ch1 行 68「父与子…以至于祂们愿意来与我们同住」用法正确，不计。）
4. **用字错误致义误 2 处**
   - ch2 行 92：「他们口里被放上**新车**」——源 `a new song put in their mouths`，应为「新**歌**」；读者会读到「新车」，义误明显。
   - ch1 行 47（圣诗第二句前）：「**妾**每仰望奇妙十架」——源 `When I survey the wondrous Cross`，应为「**我**每仰望」；「妾」全库仅此 1 处。
5. **英文残留 1 处**：ch2 行 178「**匹兹堡 Landing 之役**」——`Landing` 未译、未加括注（同句内 `Murfreesbro` 已作「默弗里斯伯勒（Murfreesbro）」处理，前文专名一律「中文（English）」），体例自相矛盾。`grep -o "匹兹堡 Landing 之役" 译文/chapter-2.zh-CN.md` 可复现。
6. **金额单位与体例错误 ≥4 处**（跨 3 章，成片）
   - ch7 行 174：「有一个人欠了**一万元**」——源 `$10,000`；「元」在中文语境指人民币，与源币种不符，且与同书 `$1,000/$500/$50`（ch4）、`$1,500/$900/$950`（ch6）、「一千元」「一千块钱」（ch3/ch6，均对应 dollars）四种写法混用。`grep -o "欠了一万元" 译文/chapter-7.zh-CN.md` 可复现。
   - 建议统一为「美元」并全书一形（数字无误，属单位/体例错）。
