# 术语表：老印第安传说（Old Indian Legends）

> 本表为翻译硬约束层。苏族（达科他）神灵、精怪、动物角色与部族文化词统一采用「音译+保留原文」策略：首次出现译作「中文（原文）」，其后单独使用中文译名。每篇译完如有新词，补充到本表。

---

## 一、神灵与精怪

| 原文 | 中文译法 | 说明 |
|------|----------|------|
| Iktomi | 伊克托米（Iktomi） | 蜘蛛精灵，苏族传说中著名的骗子神（trickster），全书主角；狡诈、虚荣、贪吃懒做，屡屡害人害己、自食其果 |
| Iya, the Camp-Eater | 伊亚（Iya），「食营兽」 | 巨人怪物，能吞下整座营地的人；绰号 the Camp-Eater 译「食营兽」 |
| Iya, the Eater | 食兽伊亚 | 《好战的七位》中 Iya 的别称（the Eater），后文简称「食兽」 |
| Old Double-Face / Double-Face | 双面老怪（Old Double-Face） | 脑袋前后各长一张脸的残暴巨人，惯于折磨弱小者 |
| Manštin | 曼斯汀（Manštin） | 兔子勇士，善良勇敢的年轻猎手（Man-štin，达科他语「兔子」） |
| Skiska | 斯吉斯卡（Skiska） | 《伊克托米与鸭子》中鸭群舞会上首先睁眼示警的那只鸭子 |
| Patkaša | 帕特卡沙（Patkaša） | 《伊克托米与乌龟》中的乌龟猎人（达科他语「乌龟」） |
| Ikto | 伊克托（Ikto） | Iktomi 的简称（《伊克托米与乌龟》乌龟背地称呼；《伊克托米和麝鼠》《伊克托米和小鹿》中亦有），保留原文
| Chaske | 查斯克（Chaske） | 《伊亚，「食营兽」》中首领为化婴的伊亚取的名字，义为「长子」 |
| Inyan | 因扬（Inyan） | 《伊克托米的毯子》中的岩石神灵，尊称「曾祖父」（great-grandfather）；坐于山坡的巨石，达科他人最爱向他祈求 |
| the Great Spirit | 大神灵（Great Spirit） | 创造树木青草的全能神灵，能听各种方式的祈祷 |
| the Generous Giver | 慷慨的赐予者（the Generous Giver） | 大神灵的别称；只受无私的感恩，不理会自私的眼泪 |
| the avenger（the badger's man-son） | 复仇者（the avenger）；獾的人儿子 | 应獾的祈祷从野牛血块中生出的人类儿子，持魔箭（《獾与熊》《被缚于树上》） |
| the magic arrow | 魔箭 | 复仇者的神箭，可连穿多头野牛；07 篇中 Iktomi 借咒语缚人于树皮亦涉此箭 |

## 四、达科他语与拟声词

| 原文 | 中文译法 | 说明 |
|------|----------|------|
| *Ištokmus wacipo, tuwayatunwanpi kinhan išta nišašapi kta* | 保留达科他语原文（斜体），其后接原文自带的英译说明「闭上眼睛跳舞……」再译为中文 | 原书体例：引语保留原语+英译，译文照此双保留 |
| *Koda Ni Dakota!* | 「Koda Ni Dakota！（朋友，你是达科他人！）」 | 鸟鸣拟达科他语，保留原语+括注意译 |
| *Zuya unhipi!* | 「Zuya unhipi！（他们出征了！）」 | 保留原语+括注意译 |
| Hĕ! / Hunhe! / Wän! / Hoye! | 哈！/ 哼嘿！/ 呀！/ 好耶！ | 感叹词用中文语气词对应，必要时首次附原文 |
| Hin-hin-hin! | 「哼－哼－哼！」 | 伊克托米哭声；Ä-bōō! 为摇篮曲拟声，译「啊——噗——」 |
| How!（问候）/ Han!（应诺） | 你好！/ 嗯哪！ | 达科他问候语 Hau 与应答；「Han, my son!」译「嗯哪，我的孩子！」 |
| Hinnú! / Ho-wo | 哎呀！/ 嗬－喔 | Hinnú 为惊呼；Ho-wo 为乌龟的应诺声（保留拟声） |
| Āhäš! / Ūun! / Ĕ han! / En! | 啊哈什！/ 呜嗯！/ 咿哈！/ 嗯！ | 拟声/应答：帕特卡沙粗嗓招呼、众人不满、鱼欢呼、兔子哼哼 |
| Hsss—tchu! / Whssh! | 嘶——噗！/ 噗嘶！ | 火入水熄灭之声 / 鱼喷水之声 |
| Hin-hin（哭调） | 哼——哼 | 蟾蜍学达科他妇女哭调时的起腔；后接所哭唤之物的名字 |
| Ah han! | Ah han！（请容我过去！） | 达科他赔礼用语（《獾与熊》獾妈妈借过时说），保留原语+括注意译 |
| Wä-ough! | 哇——嗷！ | 黑熊的怒吼（《獾与熊》两见，赶走獾一家、扑咬讨肉的獾） |
| Ahōw! | 啊嚎！ | 黑熊如中箭般的惊叫（《獾与熊》末尾惧怕复仇者时） |

| Ough! | 嚄！ | 伊克托米打寒战的惊叹（《伊克托米的毯子》） |

## 翻译策略说明

1. **音译+保留原文**：所有人名（神灵、精怪、动物角色专名）首次出现译作「中文（原文）」，此后单用中文译名；同一角色全书（含各篇）译法必须一致。
2. **达科他语引语双保留**：原书引语常以斜体达科他语+英译出现，译文保留原语（斜体）+中文意译，忠实原书体例。
3. **文化词处理**：teepee/wigwam/moccasin 等首次音译或意译加注原文，避免文化信息丢失；brave 固定译「勇士」。
4. **拟声与感叹**：用中文拟声/语气词自然对应，保留口头文学讲故事的声口。
5. 本表是硬约束：遇表内源词必按指定译法翻译。
