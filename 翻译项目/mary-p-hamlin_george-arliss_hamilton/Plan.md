## 执行步骤

单篇翻译 9 步流程（读配置 → 取 todo → doing → 读源文 → 翻译 → 自检 → check_bilingual.py → 双写 done → 日志）见 `prompts/翻译计划模板.md`「执行步骤」。本项目为委派模式，主 agent 作调度员，每篇 9 步下沉到一次性子代理执行。

- 原文为剧本对话格式（`**人物名**：台词` + 行内 `*（动作）*` 舞台说明 + 每幕开头 Scene. 场景描写），块对照按 3-6 个对白回合或一段舞台说明分组。
- 严守术语表：历史人物取通行译名，政争术语（Treasury/Bill/administration/securities）统一译法。
- act-ii 源文 >50KB，按通用翻译引擎第七节分段处理。
