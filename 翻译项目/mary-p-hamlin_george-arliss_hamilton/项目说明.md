# 项目说明

## 基本信息

- **项目名称**：mary-p-hamlin_george-arliss_hamilton
- **源语言**：英语
- **目标语言**：中文
- **内容简述**：玛丽·P·哈姆林（Mary P. Hamlin）与乔治·阿利斯（George Arliss）合著的四幕历史舞台剧本《汉密尔顿》（Hamilton, 1917）。取材自美国首任财政部长亚历山大·汉密尔顿任内遭詹姆斯·雷诺兹勒索、最终以《雷诺兹小册子》公开私情以自证清廉的真实事件。背景为华盛顿首届政府时期（约 1791–1792）的费城，政争主线是财政承担各州债务的国会法案。

## 备注

- **格式**：原文为剧本对话，提取后格式为 `**人物名**：台词`，舞台说明为整段正文或行内 `*（动作）*`；每幕开头有 Scene. 场景描写段。
- **双语块对照策略**：每个块含若干对白回合 + 舞台说明；译文块结构对应（人物名照译、台词照译、舞台说明照译）。注意人物名在对话行首与舞台说明中保持一致。
- **历史人物**：剧中绝大多数人物为真实历史人物（汉密尔顿、杰斐逊、门罗、杰伊、塔列朗等），译名取通行译法，详见术语表。
- **政争背景**：核心冲突围绕"财政承担州债法案"（the Bill）与雷诺兹勒索案，翻译时注意 Treasury/Bill/administration/securities 等政治术语的统一译法。
- **货币/价格**：台词与布景中出现的先令、便士、美元及价格（如 sixpence、two shillings、fifty cents）照译并保留数字。
- **剧本拼写**：剧中将 Talleyrand 拼作 Tallyrand，统一译"塔列朗"，不改回史拼。
- **服装表 / 场景表**：costumes.md 与各幕 Scene. 段含大量 18 世纪服饰、家具术语（cutaway coat、knee-breeches、Chippendale、Wedgewood 等），照术语表译，保留时代感。
