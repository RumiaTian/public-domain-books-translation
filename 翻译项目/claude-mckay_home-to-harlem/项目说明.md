## 备注

- **方言与俚语**：原文对白是重度黑人英语方言（Ise / gwine / youse / mah / foh / whar / kain't 等），不逐一机械还原拼写，以带口语颗粒感的中文（省略、变音、俚俗词汇）对应；叙述段落是标准英语，两者语域差异须在译文中保留。
- **种族语汇**：nigger 为时代种族蔑称，依语境译「黑鬼」，不回避不美化；Negro 译「黑人」（1920 年代通行自称，保留历史语感）；ofay、yaller、dickty、shine 等哈莱姆俚语按术语表统一处理。
- **章节标题**：格式为「罗马数字 + 标题」（如 "I Going Back Home"），译文标题合并为「I Going Back Home / 一 回家去」，罗马数字照搬不译。
- **音乐词**：blues / ragtime / jazz 译「布鲁斯 / 拉格泰姆 / 爵士」，歌名曲名保留原文附中译。
