# 术语表（班卓）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **书名**：*Banjo* 译《班卓》（副题 *A Story without a Plot*，「一部没有情节的故事」）；主角绰号 Banjo 统一译「班卓」。
- **方言与对白（核心难点）**：黑人角色大量使用非裔美式英语（AAVE，如 *Ah / evah / theah / ovah / gwine / done*），是全书声音的灵魂。译文须用一致、带粗粝市井气的口语化汉语传达其节奏与身份感，避免书面腔；勿逐字"译"方言为怪异汉字讹音，而以口语用词、语气词、句式传神。法语／普罗旺斯对白与短语保留原文并在首次出现处括注意思。
- **种族用词**：书中 *nigger / negro / darky / colored* 等词多为黑人群内部的自称与亲昵／反讽用法（McKay 的 reclaimed usage），按语境译「黑人／老黑／黑哥们／黑鬼」等，对内亲昵处用「黑哥们／老黑」类，作者议论／白人歧视语境则如实传达其刺痛感；*ofay*（黑人俚语指白人）译「白人／白佬」。
- **人名**：主要人物采用通行音译，首次出现附原文「中文（English）」，后文统一用中文。绰号（Bugsy/Ginger/Lonesome Blue 等）音译并括注。
- **地名**：法国马赛地名、街区用通行译名（马赛、老港、约列特等）；书中黑人自创的俚语地名（the Ditch / Bum Square / Boody Lane）音译＋意译并括注其真实法语原名。
- **航海／流浪黑话**：on the beach（困在港里没船上的流浪海员）、bumming／panhandling（行乞讨钱）、tramp（不定期货船）等为本书核心域词，统一采用规范译法。
- **货币**：francs 译「法郎」，sous 译「苏」（法国辅币，旧时＝法郎的１／２０）。
- **度量衡、罗马数字章节序号、书刊名（如 *Saturday Evening Post*）、人名缩写、曲名（如 *Yes, Sir, That's My Baby*、*Fleur d'Amour*）**：照搬不译，曲名可首次括注意。
- **献词**："For Ruthope" 照搬不译（作者献给 Ruth Hope，源文合写作一词）。

## 人物名

| 源词 | 译法 | 说明 |
|------|------|------|
| Lincoln Agrippa Daily / Banjo | 班卓（Banjo；本名 Lincoln Agrippa Daily） | 主角；持班卓琴的黑人流浪乐手，美国棉花带出身，一战后辗转流落马赛 |
| Malty Avis / Buchanan Malt Avis | 马尔蒂·艾维斯（Malty Avis；本名 Buchanan Malt Avis） | 西印度群岛裔，海滩帮的领袖与主心骨，"海滩上最好的鼓手" |
| Ray | 雷（Ray） | 第二部（第六章）登场，知识分子／作家型人物（McKay 的化身），海滩帮的思考者，仰慕托尔斯泰与兰波 |
| Latnah | 拉特娜（Latnah） | 肤色橄榄的小个子女人，身世不明（阿拉伯／波斯／印度裔），妓女，班卓的情人，常照料众人 |
| Bugsy | 巴格西（Bugsy） | 矮小黝黑、好斗，被众人称作 *bughouse*（疯疯癫癫）；只喝糖浆不饮酒，是帮里最清醒者；后病亡 |
| Ginger | 金杰（Ginger） | 栗色皮肤、棕黄卷发，英语圈黑人里在海滩上待得最久者 |
| Dengel | 丹格尔（Dengel） | 塞内加尔人，高瘦，会说一点英语，爱跟马尔蒂一伙 |
| Goosey | 古西（Goosey） | 浅色皮肤（*yallow boy*）的混血青年，有种族意识，善辩；后因病由领事遣送回国 |
| Taloufa | 塔卢法（Taloufa） | 西非人，被基督教传教士教育后脱离原生文化，屡遭英、法驱逐，身份文书混乱 |
| Jake | 杰克（Jake） | 班卓的老友，已"安顿下来"、套上轭的体制内海员（末章开车来接人） |
| Lonesome Blue | 孤独布鲁斯（Lonesome Blue） | 黑人海员，多次出入警局；找到船后突然人间蒸发 |
| Cuffee | 卡菲（Cuffee） | 西非青年（雷曾把一套美式衣服卖给他） |
| the chauffeur | 司机朋友（the chauffeur） | 雷在土伦结识的白人司机，怀揣小资产阶级置业梦（第二十四章主角） |
