# 项目说明

## 基本信息

- **项目名称**：《僵局》（多萝西·米勒·理查森）/ Deadlock (Dorothy M. Richardson)
- **源语言**：英语
- **目标语言**：中文
- **内容简述**：本书是英国作家多萝西·米勒·理查森《朝圣》（Pilgrimage）十三卷序列的第六部，最早的意识流小说代表作之一。延续主人公米丽亚姆·亨德森的内心历程：她在伦敦温波尔街一家牙医诊所任秘书，栖身于坦斯利街贝利太太每况愈下的寄宿舍。俄罗斯犹太青年知识分子迈克尔·沙托夫来到寄宿舍，聘米丽亚姆为英语教师；两人迅速引为知己，彻夜谈论哲学与文学，沙托夫更鼓励她从事法文著作的翻译——这是她迈向成为作家的关键一步。全书以贴紧米丽亚姆意识的自由间接引语，铺陈她对沙托夫的爱慕、对寄宿舍众生与伦敦西区的观察、对宗教与女性独立处境的反复思量，并最终在跨宗教婚恋的"僵局"（deadlock）中收束。叙事绵延流动、感官印象密集、内心独白与思绪跳跃贯穿始终。

## 备注

- 全书 13 章，单一连续叙事弧（米丽亚姆在伦敦寄宿舍与牙医诊所的日常生活、与沙托夫相识相知、跨宗教婚恋困境）。章数 ≤15 且不可分割的整体 → 中篇 → 连续模式。全书约 45.5 万字节 / 7.8 万英文词，篇幅在短篇与长篇之间，属"短长篇/中篇"体量；主 agent 连续翻译时单批受上下文限制，可分批推进。
- 与姊妹项目《尖顶屋》（卷一）同属《朝圣》序列，共享主人公米丽亚姆·亨德森及意识流语体。人物、地名、翻译策略须与《尖顶屋》术语表保持一致；本书术语表已沿用其亨德森家族译名。
- **核心风格约束**：意识流。译文必须保留米丽亚姆内向、反思、跳跃的意识语体——大量自由间接引语、省略号（……）、破折号、片段式短语构成思绪的绵延与断流，不可"理顺"为平铺直叙的外视角叙述。详见术语表"翻译策略"。
- **沙托夫的俄式英语口音**是本书特有难点：原文以谐音拼写呈现其浓重俄语口音（Pairhaps / sairtify / leeter-aytchoors / evanink / Moozayum 等）。中文不取谐音字还原，而以略带外来腔、热情而书卷气的句式传递其非母语者身份，全文一致（详见术语表"翻译策略"）。
- 文中穿插法语对白与巴黎典故，及密集的哲学/文学典故（Emerson、Spinoza、Renan、Mill、Arnold 等）。法语保留原文并紧跟中译；人名书名用通行译名。第十三章围绕犹太教皈依与跨宗教婚恋，宗教术语（Judaism / synagogue / Zionist / Unitarian 等）须统一规范译名。
- 章节标题为罗马数字 I–XIII，照搬不译。
- 说明：本 Standard Ebooks 版 metadata 明确标注本书为《朝圣》序列第六部（group-position 6，"the sixth chapter volume"），故从"卷六"；旧有"卷五"之说系早期分卷差异，以源书为准。
