# 术语表（玛格丽·阿林厄姆《布莱克·达德利罪案》）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **核心设定**：本书为玛格丽·阿林厄姆（Margery Allingham）成名作，也是名侦探阿尔伯特·坎皮恩（Albert Campion）系列的首案（1929）。一群年轻人在乡间古宅布莱克·达德利度周末，围绕一柄祖传「黑达德利仪式匕首」玩古老仪式游戏时，瘫坐轮椅的房主戈登·库姆上校（Colonel Coombe）被刺身亡；随后以本杰明·道利什（Benjamin Dawlish，真名冯·法贝尔 von Faber）为首的犯罪集团控制全宅，软禁众人。属黄金时代英国古典推理，文风兼具哥特阴郁氛围与轻快幽默，主角坎皮恩以装傻充愣的假高音腔掩盖过人智识——译文须保持这种「表象愚钝、内里精明」的反差与 1920 年代英国上流社会口吻。
- **人名**：音译为主，首次出现附原文「中文（English）」。贯穿全书的人物译法必须全书统一。
- **称谓/头衔**：Colonel 译「上校」；Dr.（医生/博士）译「医生」（Abbershaw、Whitby 均为医生）；Mr./Mrs./Miss 译「先生/太太/小姐」；Inspector（苏格兰场探长）译「探长」；Sir 译「爵士」（Sir Dorrington Wynne）。M.D.（Doctor of Medicine）保留缩写或译「医学博士」，视上下文；全书统一。
- **地名**：Black Dudley 为古宅名兼书名核心，本书统一译「布莱克·达德利」（专有名词音译，不取「黑达德利」字面意）；dagger/ritual 相关复合词随之统一。Suffolk 译「萨福克」（郡名）。
- **机构/场所**：Scotland Yard 译「苏格兰场」；the Adelphi（阿伯肖在伦敦的寓所所在）译「阿德尔菲」；the Yard 即苏格兰场简称，译「伦敦警察厅」或「苏格兰场」视上下文。
- **货币/度量**：mile 译「英里」、acre 译「英亩」等保留并首次简注；全书统一。
- **方言**：Mrs. Meade（戴西·梅·米德）讲浓厚的萨福克乡下口音（如 "What be you doing of?" "I’ve no need"），译文用带乡土味、略不规范的口语体现，与众人标准英语形成对照，全书风格一致。
- **外语**：法文短语（如 "Cherchez la Femme"，章题之一）保留原文并附译文；德语痕迹（the German / the Hun 指冯·法贝尔）照译「德国人」「德国佬」。
- **仪式术语**：the Black Dudley Ritual Dagger / the ritual of the dagger 译「布莱克·达德利仪式匕首」「匕首仪式」；玩法是熄灯后在黑暗中传递匕首（a game in the dark），相关描写照实译出。
- **章题**：原章题为罗马数字序号 + 章名（如 "I Candlelight"），中译合并为「英文 / 中文」并保留罗马数字序号，如「I Candlelight / 第一章 烛光」（罗马数字 I–XXIX 对应第 1–29 章）。

## 反派集团（the Gang）

| 原文 | 译法 | 备注 |
|------|------|------|
| Benjamin Dawlish | 本杰明·道利什 | 犯罪集团首脑「Chief」；面无表情、红脸膛（被形容像贝多芬 the man who looked like Beethoven）；真身见下 |
| Dawlish | 道利什 | 简称 |
| von Faber | 冯·法贝尔 | 道利什的真名（德国人 the German / the Hun）；国际通缉犯。首次揭示时附「冯·法贝尔（von Faber，即道利什）」 |
| Gideon | 吉迪恩 | 道利什副手；灰脸、小黑眼、嘴角常撇成「O」形；阴险 |
| Dr. White Whitby | 怀特·惠特比医生 | 库姆上校的私人看护（private attendant）；实为集团内应；逃亡后未被捕获 |
| Whitby | 惠特比 | 简称 |
| the Gang | 那伙人 / 这帮歹徒 | 题献与正文所指的犯罪团伙 |
