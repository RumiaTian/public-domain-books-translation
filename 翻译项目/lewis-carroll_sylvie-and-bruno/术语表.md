# 术语表（《西尔维与布鲁诺》——刘易斯·卡罗尔）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **书名**：*Sylvie and Bruno* 译《西尔维与布鲁诺》。全书两卷：卷一 *Sylvie and Bruno*（1889）、卷二 *Sylvie and Bruno Concluded*（1893），本书为 Standard Ebooks 合并两卷的完整版。作者 Lewis Carroll = 刘易斯·卡罗尔（《爱丽丝》作者，通行译名）。
- **本书无通行中译本**：人名地名采用规范音译/意译，全书统一即可；卡罗尔已有作品人物沿《爱丽丝》系中译传统（如 Lewis Carroll=刘易斯·卡罗尔）。
- **双线叙事**：仙境线（Outland/Fairyland）与现世线（Elveston 村）交替。叙述者为无名老绅士（「我」），靠「迷离状态」（eerie state）往返两界；两线人物在卷二逐渐交汇，身份前后呼应，译名必须全书一致。
- **儿语**：Bruno 满口幼儿语（oo=you、oor=your、oo're=you're、双重否定 "didn't never"、nuffin=nothing 等），译文用汉语幼儿口语模拟（叠词、嗲化、错语法，如「你」→「你」可作「侬/拟」不必拘泥，但全书风格统一、可读可爱），不逐词硬译；关键谐音处首现可括注原文。
- **造字与谐音命名**：卡罗尔自造词（Phlizz、Sibimet 等）一律音译并在首现处括注原文，必要处加一句注说明谐音双关（如 Sibimet 拉丁语「为他自己」，作者在卷二序言中自鸣得意；Tabikat 谐音 tabby cat「玳瑁猫/雌猫」）。
- **嵌套韵文**：全书大量歌谣、打油诗（园丁之歌各章变体、谣曲、童谣、嵌在对话中的顺口溜），译文尽量押韵保节奏；实在不可兼得时保意象与行数，不删行。原文斜体（*x*）在译文中保留斜体标记。
- **罗马数字**章序（I–XXV）照搬不译；法文/德文/拉丁文短语（L'Amie Inconnue、Mein Herr 等）按本表词条处理。
- **零宽连接符**：源文含 U+FEFF（word joiner，置于破折号前防断行，共 1700 余处），译文中一律删除，不必保留。
- **度量衡与货币**：mile/pound/guinea 等保留数字换算意译（英里、英镑、几尼），全书统一。

## 人物表（仙境线）

| 原文 | 译法 | 备注 |
|------|------|------|
| Sylvie | 西尔维（Sylvie） | 女主角，小仙子（先为 Sprite 精灵，后成为真正的 Fairy），Warden 之女、Bruno 之姊；庄重早慧。头衔 Lady Sylvie = 西尔维小姐；Fairy-Sylvie = 仙子西尔维 |
| Bruno | 布鲁诺（Bruno） | 西尔维之弟，极幼之仙童，满口儿语（见策略），自署 Bruno, Esquire（布鲁诺「先生」，Esquire 为其执拗加上的绅士头衔，谐趣处首现加注） |
| the Warden | 守护人（the Warden） | 西尔维与布鲁诺之父，Outland 合法统治者；后去位成为 King of Fairyland/Elfland（精灵王）。全书后段多称 the old Man/King |
| the Warden of Outland | 外乡守护人（Warden of Outland） | 同上，全称 |
| the Sub-Warden | 副守护人（Sub-Warden） | 篡位者，政变前的头衔 |
| Sibimet | 西比梅特（Sibimet） | 副守护人之名，拉丁语「为他自己」之谐音造名；昵称 Sibby = 西比。政变后自封 Vice-Warden，再「当选」Emperor |
| the Vice-Warden | 代守护人（Vice-Warden） | 西比梅特政变后的头衔（与 Sub-Warden 同一人，注意两阶段用词区分） |
| Tabikat | 塔比卡特（Tabikat） | 西比梅特之妻，贪吃暴虐的「夫人」（my Lady）；谐音 tabby cat（雌猫/玳瑁猫） |
| Uggug | 乌格格（Uggug） | 两人之子，骄纵丑陋的胖男孩，后变成豪猪 |
| the Lord Chancellor | 大法官（the Lord Chancellor） | Outland 宫廷高官，同谋者之一；细声尖叫的演说家 |
| the Professor | 教授（the Professor） | 仙境的老学究，推理迂阔；发明家（造出 Phlizz 的餐点、Outland 观等） |
| the Other Professor | 另一位教授（the Other Professor） | 更心不在焉的第二位教授；「另类」学究笑料担当，译名全书统一 |
| the Gardener | 园丁（the Gardener） | 反复吟唱「园丁之歌」（He thought he saw…）的疯癫园丁，卷二宴会场面的司仪 |
| the Fairy-King / King of Elfland | 精灵王（Fairy-King / King of Elfland） | 即去位后的 Warden |
| the Emperor / the Empress | 皇帝／皇后（Emperor/Empress） | Outland 改制后的帝号：西比梅特「当选」皇帝、塔比卡特为后 |
| Tottles | 托托尔斯（Tottles） | 「我先生」所唱谣曲中的主人公（年入千镑的求婚者，卷二第 13 章） |
| the Sentinel | 哨兵（the Sentinel） | 狗国的守卫獒犬（用「狗语」盘问来访者） |
| the Lion | 狮子 | Warden 化身的巨狮（「骑狮子」一章），指代同一角色时全书统一 |

## 人物表（现世线）

| 原文 | 译法 | 备注 |
|------|------|------|
| the Narrator（I） | 叙述者（「我」） | 无名老绅士，伦敦退休绅士，因体弱客居 Elveston；能于「迷离状态」见仙境，实为全书枢纽人物 |
| Lady Muriel Orme | 穆丽尔·奥姆小姐（Lady Muriel Orme） | 现世线女主角，安斯利伯爵之女；卷二成婚，卷末染疫殉难的贤者式人物 |
| the Earl of Ainslie | 安斯利伯爵（Earl of Ainslie） | 穆丽尔之父，租居「府邸」的贵族 |
| Arthur Forester | 阿瑟·福雷斯特（Arthur Forester） | 年轻医生，穆丽尔的追求者/丈夫；热忱的基督徒，多发道德议论 |
| Eric Lindon | 埃里克·林登（Eric Lindon） | 上尉，穆丽尔的表兄与订婚对象；持不可知论，与阿瑟对照；卷一末退出 |
| Mein Herr | 「我先生」（Mein Herr） | 卷二出现的神秘外国老绅士（德语「先生」之称），讲述种种乌托邦奇谈；通行做法保留德文原名，首现括注（Mein Herr，德语「老先生」），行文中可作「我先生」或「老先生」，全书统一 |
| Mrs. Hunter | 亨特太太（Mrs. Hunter） | Elveston 村民，山坡小店主人 |
| Bessie | 贝西（Bessie） | 亨特太太的小女儿 |
| the Rev. James Burgess | 詹姆斯·伯吉斯牧师（Rev. James Burgess） | 渔港牧师，疫中殉难（第 46 章剪报），配角 |
| the Guard | 列车员 | 火车线上的小配角，不入专名表亦可 |

## 地名 / 场所

| 原文 | 译法 | 备注 |
|------|------|------|
| Outland | 外乡（Outland） | 仙境中的国度，Warden 治下；字面「化外之地」 |
| Elfland | 精灵国（Elfland） | Fairyland 的行省/近称，与外乡相邻 |
| Fairyland | 仙境（Fairyland） | 泛指精灵之国，含外乡、精灵国等 |
| Dogland | 狗国（Dogland） | 狗的国度（「狗国之行」一章，君王为 Bruno 所救之犬） |
| Elveston | 埃尔夫斯顿（Elveston） | 英国北部海边村镇，现世线主场景 |
| Fayfield Junction | 费菲尔德枢纽站（Fayfield Junction） | 火车换乘站 |
| the Hall | 府邸（the Hall） | 安斯利伯爵租宅，现世线社交中心 |
| Queer Street, Number Forty | 怪街四十号 | 「我」旅馆所在的奇街（第 19 章）；意译即可 |

## 专有名词 / 造字 / 歌谣 / 称谓

| 原文 | 译法 | 备注 |
|------|------|------|
| Phlizz | 菲利兹（Phlizz） | 卡罗尔造字：徒有其表、不可实用的幻物（假花束、无味的点心）；音译+首现括注 |
| the "eerie" state | 「迷离状态」（eerie） | 叙述者半梦半醒、可见精灵的状态；苏格兰语 eerie；首现括注，后文统一「迷离状态」 |
| fairyish | 仙气飘飘／有点灵异（fairyish） | 按语境二选一，同段保持一致 |
| the Royal Road | 王家大道（the Royal Road） | 仙境捷径：唯王与王亲可行，故咫尺即达 |
| the Magic Locket | 魔法挂坠盒（the Magic Locket） | Warden 赠西尔维的小盒，内藏红宝石坠 |
| the little red star | 小红星（the little red star） | 挂坠盒中宝石；「看它是红星、透过它是蓝天」，全书核心象征，末句点题 It is love |
| y'reince | 殿下（y'reince） | your Royal Highness 压成单音节的宫廷新造敬语（五个音节读成一个的绝技）；译「殿下」并于首现处括注原玩笑 |
| Mister Sir | 先生先生（Mister Sir） | Bruno 对男子的叠称敬语，保留叠称趣味 |
| the Gardener's Song | 园丁之歌 | 各章变体反复出现的打油诗，首行均为 He thought he saw…（他以为自己看见……） |
| Matilda Jane | 玛蒂尔达·珍妮（Matilda Jane） | 童谣名/歌名（第 33 章） |
| The Man in the Moon | 月中人（the Man in the Moon） | 章名与歌谣 |
| Gammon and Spinach | 火腿与菠菜（Gammon and Spinach） | 旧歌谣名（第 48 章，出自 Nursery rhyme "A Frog He Would A-Wooing Go"） |
| L'Amie Inconnue | 《无名女友》（L'Amie Inconnue） | 第 3 章法文章名，首现保留法文并附译 |
| the Ivory Door | 象牙门（the Ivory Door） | 仙境之门（第 22 章），意译 |
| the Farewell-Party | 欢送会 | 第 37 章， Mein Herr 讲学的聚会 |
| the Money-Act | 币制法案 | 代守护人的「政绩」，配角词 |
| the pig-tale | 猪的故事 | 第 51 章 The Pig-Tale（Other Professor 的诗），双关 pig-tail；首现可注 |
