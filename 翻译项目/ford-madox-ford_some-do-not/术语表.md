# 术语表（ford-madox-ford_some-do-not）

> 《Some Do Not...》（《行进尽头》四部曲第一部，Ford Madox Ford, 1924）。
> 建表方式：通读全书 13 章文本提取。**人物/地名译名为硬约束**，遇表内源词必译为指定译法；新词由译者补入本表。
> 本书为四部曲之首，人名/地名译法需为后三卷（No More Parades / A Man Could Stand Up — / Last Post）沿用预留。

## 六、引文·外语处理策略

| 类型 | 策略 |
|------|------|
| 书名出典 | 书名 Some Do Not... 出自书中所引歌词 "To the gods to each ascribe a differing lot: Some enter at the portal. Some do not!"（有神各赐命数不同：有人自正门而入，有人不得其门）；第一部中文书名暂定《有些人没有……》，随系列（《行进尽头》四部曲）定名统一 |
| 德语诗（海涅） | "Die Sommer Nacht hat mirs angethan…"：保留德文原文（块引用内），紧随汉译；书中人物自带的英文拙译（"It was the summer night came over me…"）照译成中文的「生硬直译腔」以保留效果 |
| 英语歌谣 | "Somewhere or other there must surely be / The face not seen…"（末章）：按韵文照译 |
| 爱尔兰歌谣 | "Rich and rare were the gems she wore…"（摩尔《爱尔兰歌谣》）：按韵文照译 |
| 拉丁文 | 奥维德等引文（'Terra tribus scopulis vastum procurrit'…）：保留拉丁文，紧随括注汉译；人物争论校勘（vastum/longum、altum）时涉及的拉丁词一律原样保留 |
| 法语 | 短语（maussade 等）：保留原文并括注，或依上下文意译融入 |
| 罗马数字 | 章节编号照搬不译（见下） |

## 七、总体翻译策略

- **章节标题**：合并格式「## Part I / 第一部」「### I / 第一章」——原文侧保留罗马数字，中文侧用汉字序数，全书统一。
- **人名地名**：首现附原文「中文（English）」，此后统一用译名；姓氏不拆译（Port Scatho 为复合姓）。
- **称谓**：Mr./Mrs./Miss + 姓 → 某先生/某太太/某小姐；名加姓连用时只译姓（"Mrs. Duchemin said" → 迪谢曼太太说）。
- **叙事风格**：福特式时间跳切（time-shift）——叙述在回忆与现在间骤然切换，**不强行理顺时序**；长句保留绵延感，对白按角色语体（西尔维娅尖利机敏、将军和蔼威严、麦克马斯特拘谨虚荣、万诺普太太爽利）。
- **零宽字符**：原文含 U+FEFF/U+200A（Standard Ebooks 排版用），译文中一律清除。
- **系列一致性**：蒂金斯/瓦伦丁/西尔维娅/麦克马斯特/格罗比/坎皮恩等核心译名为四部曲统一基准，后三卷建项目时沿用本表。
