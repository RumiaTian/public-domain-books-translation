## 执行步骤

按 `prompts/翻译计划模板.md`「执行步骤」9 步推进（读配置 → 取 todo → doing → 读源文 → 翻译 → 自检 → check_bilingual.py → 双写 done → 日志）。

> 长篇（>50KB：04-adventure-of-the-missing-brother）按通用翻译引擎第七节分段处理，单篇不可中途截断。
> 连锁结构提醒：各章化名（伯顿/威尔金斯/拉利/莱斯特等）对应真身见术语表，跨章统一；嵌套手稿（利普修斯、克拉多克自述）语气与主线区别处理。
