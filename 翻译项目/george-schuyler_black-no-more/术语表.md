# 术语表 — Black No More（黑色的终结）

> 三列：译法（音译/意译）｜原文｜处理策略说明。
> 本表为翻译硬约束：遇表内源词必按指定译法。新词由译者补充，首次出现附原文「中文（English）」。

## 人物

| 译法 | 原文 | 处理策略 |
|------|------|----------|
| 马克斯·迪舍尔 | Max Disher | 主角。音译；变白后化名也需统一处理（原文别名 William Small 译作「威廉·斯莫尔」） |

| 菲莉斯·惠特利酒店 | Phyllis Wheatley Hotel | 音译（人名，美国首位黑人女诗人），全篇统一 |

| 道格拉斯银行 | Douglass Bank | 音译（人名，弗里德里克·道格拉斯），全篇统一 |
| 第十五团 | 15th regiment | 意译，指一战黑人部队（哈莱姆地狱战士所属部队传统） |

| 北欧骑士团 | Knights of Nordica | 白人种族主义组织。意译，Nordica 指北欧人种，讽刺意味需保留 |
| 回非洲运动协会 | Back-to-Africa Society | 意译 |
| 共和党 / 民主党 | Republicans / Democrats | 意译，涉及书中政治讽刺需区分两党立场 |

## 种族议题用语

| 译法 | 原文 | 处理策略 |
|------|------|----------|
| 黑人 / 黑人同胞 | Negro | 历史语境用语，中性直译「黑人」，大写 Negro 为当时庄重称谓 |
| 非美人 | Aframerican | 作者生造词（African + American），译「非美（黑人）」，首次加注 |
| 黑gui / 黑崽子（视语气） | darky | 蔑称，按语境译「黑崽子/黑鬼们」，保留冒犯语气但避免过度重复现代最恶劣蔑称 |
| 黑鬼 | nigger | 强蔑称，如实译出（原著讽刺需要），全书统一 |
| 白鬼 | ofay | 黑人俚语对白人的蔑称，译「白鬼」，首次可加注 |
| 红脖佬 / 南方白佬 | cracker | 对南方贫穷白人的蔑称，译「南方白佬/红脖佬」，统一 |
| 黄皮肤姑娘 | yallah (gal) / yellow women | 指浅肤色黑人女性（high yallah），译「黄（皮肤）姑娘」，保留原文肤色等级观念的讽刺 |
| 混血儿 | mulatto / octoroon | 历史种族分类词，直译「混血儿/有八分之一黑人血统者」，octoroon 首次加注 |
| 吉姆·克劳（种族隔离） | Jim Crow | 专有名词音译，「No more Jim Crow」译「再不用受吉姆·克劳（种族隔离）的气了」 |
| 变白手术 / 疗法 | the treatment / operation | Black-No-More 疗法通称，译「变白疗法/手术」，统一 |
| 黑人地带 | Black Belt | 指黑人聚居区，译「黑人区（Black Belt）」，首次附原文 |
| 白人至上 | white supremacy | 意译 |
| 种族问题 | race problem | 意译，全书核心概念，统一 |
| 白肤化 / 变白 | passing / turn white | passing 指冒充白人，译「冒充白人（passing）」，首次加注 |
