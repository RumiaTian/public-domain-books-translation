# 术语表（《世界末日》）

> 翻译硬约束层。遇表内源词必译为指定译法；新词首次出现以「中文（English）」标注，译完后补充进本表。

## 翻译策略

- **本书性质**：杰弗里·丹尼斯 1930 年出版的哲理散文／文学性论著，围绕「世界末日」单一主题展开四部分论证（How? / When? / Which First? / What After?）。文笔华丽、用典繁密，旁征博引自古罗马至当代的天文、宗教、史地、神话。译文须保持其文学性抒情笔调与雄辩节奏，不可干瘪直译。
- **人名**：西方历史人物、作家、君主一律用通行中文译名（见人物表）。生僻人名首次出现附原文「中文（English）」，其后统一用中文。
- **地名**：古今地名用通行中文译名（罗马、耶路撒冷、拜占庭等）。
- **天文／科学专名**：用天文学界通行中文译名（银河、比邻星、猎户座、木星、海王星等）。德文术语 Wärmetod 保留德文原文并译「热寂」，首次出现标注。
- **宗教／神话术语**：基督教术语（Parousia、Dies Irae、chiliad 等）用教会／学界通行译法；希腊罗马神祇用通行译名（雅典娜、阿波罗）。
- **拉丁文／希腊文原文**：作者大量引用拉丁文、希腊文短语及诗句。策略：保留原文，后附中译；短词可在括号内给义，长诗句单独成行先原文后译文。数字卦象（如 PΩMH=948）照搬不改。
- **罗马数字、年份、世纪数字、度量数值**：照搬不译；「BC／AD」可译「公元前／公元」。
- **作者自称**：末章出现 "I Geoffrey"（作者杰弗里·丹尼斯自指），译「我，杰弗里」。
- **章节标题**：四部标题为疑问短语（How? / When? / Which First? / What After?），子章为单词（Comet、Fire…）。标题译为中文，按双语对照规则合并「英文 / 中文」。
