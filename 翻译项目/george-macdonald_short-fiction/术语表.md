# 术语表

## 跨篇母题/专名

| 原文 | 译名 | 说明 |
|------|------|------|
| Lilith | 莉莉丝 | 亚当第一任妻子、夜之魔女（MacDonald 核心象征，《残忍的画师》等篇出现） |
| Christ | 基督 | MacDonald 是基督教作家，宗教意象频繁 |
| fairy / fairies | 仙灵 / 仙人 | 苏格兰民间传说中的异类生灵 |
| brownie | 棕仙 | 苏格兰民间小精灵（家中帮工精灵） |
| kelpie | 水马 | 苏格兰民间传说中的水妖 |
| Ossian | 奥西恩 | 古盖尔语吟游诗人（Macpherson 伪作争议） |
| Macpherson | 麦克弗森 | 奥西恩诗集的"译者"（实为伪作） |

## 译法策略

- 各篇人物名由译者首次出现时确定统一译法，附原文「中文（English）」。
- **苏格兰地名**：用通行音译（如 Edinburgh=爱丁堡、Glasgow=格拉斯哥、Inverness=因弗内斯）。篇内虚构地名按音译。
- **Märchen**：德语"童话"，"A Day and Night Märchen"=一日一夜的童话，标题保留原味译。
- **the carasoyn / the wow o' rivven**：苏格兰方言标题，保留原词并意译副标题/注释。"carasoyn"=一种精灵/小妖，"wow o' rivven"=撕裂之痛/惊呼。
- **glen / loch / brae / muir**：苏格兰地形词（峡谷/湖泊/山坡/荒原），可酌情音译或意译，全篇一致。
- **Mac- / Mc-** 姓氏：译"麦-""麦克-"（Macintosh=麦金托什、MacDonald=麦克唐纳）。
- 货币：pound/shilling/guinea/sovereign=英镑/先令/几尼/索维林。
- 童话重复结构（"once upon a time""there was a"）保留故事开篇的"从前""有这样一个"。
- MacDonald 长句多，翻译允许适当拆分为符合中文节奏的短句，但保留其沉思的节奏感。
